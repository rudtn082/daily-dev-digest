# Daily Dev Digest — 2026-09-30

> Theme: The action moved from the model to the layer around it — harnesses, code graphs and context that agents can't drift from.

## Picks

### DeepSeek Harness — DeepSeek's own open-source agent harness
MIT-licensed agent harness (`dsh`) that DeepSeek open-sourced on August 13. Its pitch is "everything is a plugin": the model adapter, tool registry, session log and even the agent loop are replaceable, and it ships with a Web UI you can start with `npx @deepseek-ai/dsh web`. It's still in developer preview, but it keeps showing up in this month's trending roundups — a model lab shipping the harness itself is a shift from "here's a model" to "here's the whole rig".

### Faber — a terminal coding agent that reads less of your repo
Free, open-source terminal coding agent that uses a code graph to find the relevant files, symbols, callers and dependencies before loading any context. It works with Claude, OpenAI Codex and local models, with Git-aware workflows, undo/redo, memory and token/cost tracking, and installs from npm as `faberwright`. It's a recent Show HN-era launch aimed at a real pain: agents that read far more of the repo than the task needs, and bill you for it.

### Meetless — an "active source of truth" between you and your coding agents
Apache-2.0 CLI (`mla`, public beta) that watches agent sessions, captures decisions as work happens, detects conflicts and injects human-approved context before each agent turn. It also tracks repo rules and injects them when an action triggers them. It was a recent Show HN and fits the theme: as people run agents in parallel, keeping them from drifting is becoming its own tool category. Its benchmark claims are the author's own — test them yourself.
