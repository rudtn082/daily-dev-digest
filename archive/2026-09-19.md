# Daily Dev Digest — 2026-09-19

> Theme: Less noise, more parallel — agents get a diet for their output, a home for their branches, and a model that loops on itself

## Picks

### i-have-adhd — a skill that makes coding agents lead with the action
A skill/plugin that applies ten rules to force direct, action-first output: instead of "Let me think about this… hope this helps", you get `npm install jsonwebtoken@latest`, then edit `src/auth.ts:42`, in numbered steps. It's on the radar because it climbed GitHub trending in the week of Sept 9–15 and works across Claude, Cursor, Gemini, Kimi and Qwen — the "buried answer" complaint turned out to be nearly universal.

### context-mode — an MCP server that keeps tool output out of the context window
Sandboxes tool results in isolated subprocesses so raw data never enters the conversation (the project claims a 98% reduction), and keeps session state in SQLite with full-text search so the agent can resume after compaction. It's here because context burn in long agent sessions is now the bottleneck people feel daily, and this attacks it at the tool boundary across 17 platforms rather than inside one agent.

### worktrunk — git worktrees as easy as branches, built for parallel agents
A Rust CLI where `wt switch`, `wt list` and `wt remove` cover the core worktree workflow. Once you run several agents at once, each needs its own checkout, and raw `git worktree` becomes the friction — that's the gap it fills, and why it trended this week. MIT or Apache 2.0.

### Recurrent Looped Transformer (RLT) — pass the last hidden state to the next token
An architecture that recurs across prompt and response by feeding the decoder's final hidden state forward, with sliding-window attention caches per layer and global KV memory from the encoder. The project page reports six algorithmic tasks, 108 runs: on 256-bit parity some RLT-1 variants hit 100% on all three seeds while Transformer-8 reached about 50%. Small-scale and self-reported, but a concrete look at recurrence returning to LLM design.
