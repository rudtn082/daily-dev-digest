# Daily Dev Digest — 2026-10-22

> Theme: Fences for agents — a permissions spec, a hands-off build plugin, and a language built to keep the models out.

## Picks

### Docker Sandbox Kit Spec v3 — an open spec that puts an agent's permissions inside its container image
A Kit is an ordinary OCI image whose manifest annotation declares what the agent may reach: network hosts (down to HTTP methods and paths), credentials, volumes, ports. The host approves each request, and a new Kit version that asks for more access than the last approved one needs fresh approval. It's on the radar because agent permissions are moving from ad-hoc prompts to something you can sign, version and review like code. Apache 2.0; Docker says it plans to submit it to the CNCF.

### Superlite — a Claude Code plugin that takes a spec and builds without stopping to ask
Give it a spec, approve one plan, and it splits the work into parallel tasks, assigns models, reviews the results and logs its decisions. It's the deliberate opposite of Superpowers' step-by-step approvals. The author's benchmark (16.1 min vs a 33.6 min mean, all 177 hidden tests passing) is a single self-run, so treat it as an anecdote. It hit the Hacker News AI digest this week.

### KillSwitch — an esoteric stack language designed to be hard for LLMs
Dominik Picheta's language is meant to be readable by humans while tripping up coding agents: a spec with hidden lies, an interpreter that enforces letter-count rules, constructs that try to set off guardrails, and "Ignore previous instructions" given a defined meaning. Picheta's own benchmark topped out at 66.8 and he cautions that the tasks were simple. Worth a look as a playful probe of how models fail on unfamiliar specs; it drew heavy Hacker News discussion.

### Timestral — Mistral's first time-series foundation models
Four sizes (5M to 209M parameters) for zero-shot probabilistic forecasting, with a 32,768-step context, 21-quantile output and CPU inference. Modified MIT license, with code on GitHub. It's notable as Mistral stepping outside language models into small, cheap, runnable-anywhere forecasting. Check the license terms and weights availability on the model page before building on it.
