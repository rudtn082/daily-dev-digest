# Daily Dev Digest — 2026-11-20

## Picks

### CVE-2026-115560 — a third PHP session-handler RCE, with no patch yet
PHP disclosed another remote code execution flaw days after the PHP2Shell emergency patches. It needs a narrow setup: an app starts with `session.serialize_handler` set to `php_binary` or `php_serialize`, switches it to `php` at runtime before `session_start()`, and session upload progress stays enabled. PHP says there is no fix yet and recommends setting `session.upload_progress.enabled` to 0 until the next regular release. Affected versions and severity were not yet named, so check the advisories.

### xj-scanner — open-source tooling for 1991–95 Jeep and Chrysler engine computers
An owner used a cheap Arduino Nano to connect Claude Code and Codex to the ECU of a 1994 Cherokee that was failing a smog check. The scanner behind it is reportedly GPLv3 and covers SBEC (OBD1) computers. On the radar because it hit the Hacker News front page and shows agents doing real reverse-engineering on legacy hardware. It is one owner's account, not independently reproduced, and changing ECU behavior can affect drivability and emissions.

### T3 Code — a local control plane for several coding agents
Free, open-source app that launches agents such as Claude Code, Codex, Cursor and OpenCode from one local server, viewable in browser, desktop or mobile, with git worktrees, plan mode, a diff viewer and PR creation. Shareuhack's weekly trending lists had it as the fastest-growing repo in early November. Sources disagree on the official repo (pingdotgg/t3code vs t3-oss/t3-code), so confirm before installing.
