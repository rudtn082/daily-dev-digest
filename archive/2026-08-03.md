# Daily Dev Digest — 2026-08-03

> Theme: The agent isn't the product anymore — the plumbing around it is: what it can see, what it can touch, what it can read, and who supervises it.

## Picks

### Screenpipe — a 24/7 local work ledger your agents can query
The reframe in July was the whole pitch: stop selling screen recording, sell "record how you work → searchable memory → SOPs your agents can execute." Screen and audio go to a local SQLite database on your machine and out through MCP, so an agent watching you repeat a task can write the steps down instead of being prompted through them each time. Everything stays local, which is the only version of this idea most people would tolerate. The YC S26 Launch HN thread and a 260K-view relaunch put it back in front of a lot of people who had written it off as a novelty.

### Coasty — an API for computer-use agents, with the runtime open-sourced
You send a natural-language task, pick a machine or browser environment, hand over the credentials and files it needs, and the agent drives the interface via screenshots, mouse and keyboard, then verifies the result before returning. What makes it worth a look over the closed offerings is `coasty-ai/open-computer-use`, which lets you run the same loop yourself with a single API key rather than committing to a hosted black box. Computer use is where agent demos go to die, so anything that ships a runnable open version is useful signal.

### Context.dev — clean web context for agents, as one boring API
Scrape a URL into LLM-ready markdown, extract to your own JSON schema, or crawl a whole site with sitemap discovery — with JS rendering, anti-bot handling and stealth proxies folded into every request at no extra credit cost. That last detail is the point: everyone building agents rebuilds this layer, and the tax is usually paid in proxy bills and per-feature upsells rather than in code. Another YC S26 launch, free tier included, and a reminder that "give the model good input" is still an unglamorous infrastructure problem.

### OpenHands Agent Canvas — a self-hosted control room for whatever agent you already use
Rather than pitching another coding agent, it supervises the ones you have: OpenHands' own, Claude Code, Codex, Gemini, or anything speaking the Agent Client Protocol, all on one self-hosted canvas. ACP being the seam is the interesting part — it implies the next fight is over the orchestration surface, not the agent, and that teams running three vendors' agents in parallel are common enough to build for. Worth watching whether the protocol holds as more agents adopt it.
