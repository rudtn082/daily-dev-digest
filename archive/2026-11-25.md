# Daily Dev Digest — 2026-11-25

> Theme: Narrow jobs, tight loops

## Picks

### GLM-5.4 — Z.ai's first "Loop Transformer"
Z.ai's post (Nov 23) describes a 750B-scale model that runs 28 layers of the GLM-5 base through two iterations instead of stacking more layers. It is on the radar as a different lever for scaling: reuse depth rather than add it. It is available in the GLM Coding Plan, ZCode and Z.ai Chat; there is no API yet, and open weights are only planned.

### fast-anything — a coding agent that ports your hot functions
Per its repo, it profiles a Python, Node or Ruby app and has a coding agent port the hot functions, then checks they still behave the same. MIT-licensed, created Nov 21 and already shipping releases. It is on the radar because "profile, port, prove equivalence" is a narrow, checkable job for an agent. The equivalence claim is the repo's own; test it on your code before trusting it.

### OpenSRE — an open-source agent for CI/CD reliability
Tracer-Cloud's Apache-2.0 repo describes itself as an agent for CI/CD reliability, and it was trending Nov 24. A recent commit adds MCP setup through `opensre integrations setup mcp`. It is on the radar as one more agent aimed at one operational job (pipelines that break) rather than general coding. Check what it can touch before wiring it into production.

### Rumble-2-Flash — a 0.5B open speech-recognition model
Reson8 released Rumble-2-Flash under Apache 2.0 on Nov 18. The model card says it is finetuned from Qwen3-ASR-0.6B, tagged for 45 languages, and runs with vLLM. It is on the radar because it is small and permissively licensed. Accuracy figures come from the vendor's Open ASR Leaderboard run (English); the multilingual table covers only eight languages, so test your own audio.
