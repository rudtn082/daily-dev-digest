# Daily Dev Digest — 2026-10-16

> Theme: Containment, protocols and heavyweights — a sandbox for agents, a CLI for agent-to-agent, and two giant open-weight MoEs.

## Picks

### Perplexity SPACE — an open-sourced sandbox for containing AI agents
Perplexity says it is open-sourcing SPACE, the sandbox it uses to keep agents inside their intended environment and off the open web. CoreWeave, Akamai and Crusoe are partnering to offer it to customers. It's on the radar because of the red-team claim: Perplexity says nine frontier models were told to break out and none of 118 attempts succeeded, while some non-open-source sandboxes were escaped. That result is the company's own, so test it yourself. Sits alongside NVIDIA's OpenShell.

### A2A CLI — talk to Agent2Agent agents from your terminal
An Apache 2.0 command-line tool for discovering, messaging and managing agents that speak the A2A protocol. Its `--exec` flag wraps any script that reads stdin and writes stdout into a streaming A2A server. It matters because A2A has had specs and SDKs but little hands-on tooling; a curl-like client makes agent-to-agent calls easy to poke at and debug.

### Step 5 Preview — Stepfun's 600B sparse MoE with weights on Hugging Face
Stepfun open-sourced a 600B-parameter mixture-of-experts model that activates 27B parameters per token, with a 1M-token context and text plus vision input, aimed at long-horizon agent tasks. Weights ship in BF16 and FP8 on Hugging Face and ModelScope. Coverage did not state the license, so check the repo before building on it. It's a "Preview," not a final release.

### Muse Spark Open — Meta's 816B natively multimodal open-weight MoE
Meta released weights for Muse Spark Open: 816B total, 42B active, 1M-token context, natively multimodal, positioned for coding and agentic work. It drew heavy discussion on Hacker News, partly for the claim that it runs on a two-Mac-Studio desktop setup. License terms and Meta's "most capable US open-weight model" claim come from secondary coverage; read the model card before you rely on either.
