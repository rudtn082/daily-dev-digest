# Daily Dev Digest — 2026-10-30

> Theme: Code at agent scale — and the tools that prove, test, or restrict it.

## Picks

### Gemini 4 Carbon — Google's cyber-focused frontier model, defenders only for now
Announced Oct 28, two weeks after Gemini 4 Argon. Google says it is its strongest model for cybersecurity and long-horizon work, but access starts with a subset of cyber defenders, then trusted partners via the Fairwind Program. Benchmark figures are Google's own and not independently verified.

### GitHub Octoverse 2026 — the numbers behind agent-written code
GitHub's annual report, as summarized by Simon Willison from remarks by Jay Parikh: 220M merged PRs per month, 7.38B commits per month, 30.3M new repos per month. Willison credits agentic engineering for the tripling. Useful as a baseline for how fast review and verification load is growing.

### Lasm — formally verified web apps in Lean, compiled to WebAssembly
Show HN (Oct 30). An MIT-licensed toolchain that compiles Lean 4 to WebAssembly ahead of time to run on Node, serverless, edge, WASI and browsers; ships as `@lasm/cli` on npm. Its RealWorld example app, Conduit, carries 117 proved theorems. Early and small, but a concrete answer to "who checks the agent's code".

### Doomformer — a neural network built out of DOOM maps
Show HN (Oct 30). Converts integer neural networks into ZDoom-format maps run through ViZDoom: voodoo dolls do the arithmetic, light levels and plane heights store results, and Python checks every value against a NumPy integer reference with zero tolerance. Pure weird-but-cool.
