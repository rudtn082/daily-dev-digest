# Daily Dev Digest — 2026-10-21

> Theme: Fast, small and big — a diagram renderer 500× faster, a 12B coding model with 2.5B active, and Google's frontier model going generally available.

## Picks

### Gemini 4 Argon — Google's frontier model, now generally available
Google opened Gemini 4 Argon to developers on October 13 after a limited preview that began September 30. Reported specs: roughly 1M-token context, about 1M tokens of output per run (up from 64K), and an introductory price of $2 / $10 per million input / output tokens through November 30, doubling in December. Reports say Artificial Analysis puts it roughly level with GPT-6 Astra; that and Google's prompt-injection resistance claims are not independently verified. It matters because it is Google's first model in a while pitched as level with the top closed models, and the 1M-token output limit changes what a single agent run can produce.

### Mellum 2.1 — JetBrains' open 12B MoE coding model
JetBrains released Mellum 2.1 on Hugging Face under Apache 2.0: a mixture-of-experts model with 12B total and about 2.5B active parameters. The architecture matches Mellum2; the work went into reinforcement-learning post-training, which JetBrains says lifts SWE-bench Verified from 2% to 47% and LiveCodeBench v6 to 82%. Those figures are self-reported and unverified. It matters as a small, permissively licensed coding model trained from scratch by a tools vendor, cheap enough to serve yourself.

### Pele — a zero-dependency Mermaid-to-SVG renderer
Pele renders Mermaid syntax to themeable SVG without a browser DOM; colors and fonts are CSS variables, so a theme change needs no re-render. Its own comparison claims 0.05–0.3 ms per diagram versus 6–82 ms for Mermaid.js and 230 kB gzipped versus 1.6 MB; measurement conditions are not documented. It uses its own layout engine, so node and edge placement differs from Mermaid's. It matters because diagram rendering in notes apps and agent output is usually slow and heavy, and this trades layout fidelity for speed. It surfaced on Hacker News around October 17.
