# Daily Dev Digest — 2026-10-29

> Theme: Giving agents structure — design reviews, agents-as-code, and a speech model that remembers who said what.

## Picks

### Nemotron 3.5 Transcribe — Nvidia's open speech model that transcribes, translates and labels speakers
Nvidia released an open-weight, promptable speech model on October 28 (Hugging Face repo `NVIDIA-Nemotron-3.5-Transcribe-30B-A4B`). One checkpoint handles transcription in 40 languages, translation for 31 of them, speaker labels for 13, and recordings up to an hour with up to eight speakers. It's on the radar because it's reported to top the Hugging Face English Open ASR Leaderboard among open-weight models, with a 5.33% average word error rate. Sources disagree on exact parameter counts (30B vs 34B total), so check the model card.

### Agent SDK — Cursor's framework for defining agents as code
Cursor published the Agent SDK on October 20: prompts in Markdown, tools as TypeScript functions, with evals, event replay and PR triggers from GitHub, GitLab or Bitbucket, deployable to Cursor's hosting or your own container. It's the same framework behind Cursor's own Bugbot, Security Reviewer and Rollouts. It matters because it treats an agent as a reviewable, versioned project rather than a product setting. Pricing is token-based per a third-party report; confirm on Cursor's site.

### Elephant-Goldfish Model — Google open-sources its design-before-code agent workflow
Google released the Elephant-Goldfish Model plugin under Apache 2.0 on October 22, initially for Antigravity. An "Elephant" agent with full project context drafts a design doc, then "Goldfish" reviewers with no prior conversation attack it for hidden assumptions, and you approve before any code is written. It's worth a look because it's an internal workflow Google says its engineers use daily, now inspectable and forkable.
