# Daily Dev Digest — 2026-07-27

> Theme: Nobody shipped a new idea today — they shipped the missing piece that made an old one usable

## Picks

### oMLX — an MLX inference server that stops your Mac recomputing the same context
Local coding agents on Apple Silicon have had one killer flaw: an agent sends dozens of requests whose prompt prefix keeps shifting, and every MLX server invalidates the KV cache when it does, so you re-compute the whole context and wait 30–90s a turn. oMLX persists KV cache blocks to disk as pages, so when a prefix comes back it's restored instead of recomputed — users report time-to-first-token collapsing to a few seconds on long contexts. It also serves VLMs, OCR models, embeddings and rerankers, and it's driven from a macOS menu bar app with an admin web UI. It's on the radar now, months after it first appeared, because open-weight models finally got good enough that people actually want to run agents locally.

### Inkling — Thinking Machines Lab's first model, 975B open weights under Apache 2.0
Released July 15: a 975B-parameter mixture-of-experts with 41B active per token, a 1M-token context, native reasoning across text, images and audio, pretrained on 45T tokens. Weights are on Hugging Face under Apache 2.0, with a lighter Inkling-Small preview alongside. What makes it notable isn't a benchmark claim — the lab explicitly says it isn't going for strongest-overall — it's the license on a model this size from a US lab, positioned as a customizable base to fine-tune rather than an endpoint to call. That's a different bet than everyone else is making.

### Infini-News — 1.36B Common Crawl news articles you can actually query
Large-scale news corpora are the backbone of a lot of computational social science, and access has been the whole problem: commercial archives are priced out of reach, and the open alternative, Common Crawl's CC-News, is terabytes of raw data that needs serious compute before it's usable. Infini-News does that work once — extracts and cleans text and metadata for over 1.35B articles from 2016 onward, tags language with three classifiers, resolves a country of origin for 83.4% of articles across 222 countries — then builds infini-gram suffix-array indexes so you can pattern-search the whole archive in sub-second time. The dataset is on Hugging Face. Preprocessing as a public good.

### Fruitbox — Docker Compose for Apple's own container runtime
Apple's `container` shipped and hit 1.0, but a native runtime is only half of what people actually use Docker for; the other half is a `docker-compose.yml` that brings up five services at once. Fruitbox fills that gap, running Compose files against Apple's runtime. It's here less for the tool itself than for the signal: a community tooling layer — Compose equivalents, Docker Desktop-style GUIs — is now forming around Apple's runtime, which is what has to happen before it's a real Docker alternative on a Mac rather than a curiosity.

### Frond — the dependency graph your React app already has, made explicit
Frond isn't a router, a renderer, or a component framework — it's the layer underneath, where services, resources, identity, readiness and cleanup actually live. Each node declares its dependencies, how it's acquired, cancelled and released, in one place; the runtime resolves them in order and tracks readiness, so `useNode` suspends until a node is ready instead of every component re-deriving that logic itself. Lifecycle guarantees run on Effect, so when a node evicts, in-flight work is genuinely interrupted: fetches abort, timers clear, streams close. A blunt argument that the hard part of frontend was never rendering.
