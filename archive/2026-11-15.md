# Daily Dev Digest — 2026-11-15

> Theme: Trust at the edges — a package index that says when it can't vouch for a release, an app builder whose apps leaked data, and the plumbing (ggml, a browser for agents) that local AI runs on.

## Picks

### PyPI provenance warnings — releases now say when their origin can't be verified
PyPI's Nov 6 UI update adds a security tab showing each release's provenance and per-file attestations, plus warnings when provenance is missing, incomplete, inconsistent, changed, or lost. On the radar because it makes supply-chain gaps visible at install-decision time. A Hacker News commenter noted it helps with hijacked formerly-benign projects but does not detect outright malicious ones. Many older releases simply have no attestations.

### Lovable apps leak — researchers scanned 159,041 projects and found open Supabase data
A research write-up reports Lovable-built, Supabase-backed apps exposing data without login, including a forum with 200,000 private messages and a provider with 1,000+ identity records with passport numbers. Lovable's head of security attributes it to insufficient Row-Level Security and points to free pre-publish scans and auto-fix. On the radar because it is a concrete case of generated apps shipping with default-open data. If you ship AI-built apps on Supabase, audit your RLS. Findings are the researchers' claims; the vendor's response is quoted from HN discussion.

### ggml 1.0.0 — llama.cpp's tensor library prunes legacy API and adds FP8
The 1.0.0 release removes deprecated APIs and legacy DIAG_MASK ops, bumps the RPC protocol to v9, adds OCP FP8 support and configurable YaRN truncation, and lands performance work across CUDA, Metal, Vulkan, SYCL, OpenCL, WebGPU, Hexagon and CPU backends. On the radar because a 1.0 marks a stability point for the library under much local inference, and the API cleanup can break downstream code. Details are from a mirror's summary of the release notes.

### Agweb — a WebKit browser for coding agents that never steals focus
macOS browser with one window that never takes focus, controlled from the shell via an `agweb` command modeled on playwright-cli; you watch all tabs live. Lists idle tab suspension, shared login profiles and secret handling. On the radar because agents driving your desktop browser keep grabbing focus, and headless browsers are heavy. The page I found did not state a license; check the repo.
