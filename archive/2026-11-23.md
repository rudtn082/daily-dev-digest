# Daily Dev Digest — 2026-11-23

> Theme: Agents get managers, gateways and bouncers

## Picks

### Devin Bots — Cognition's persistent manager agents for teams of Devin coders
Cognition launched Devin Bots on Nov 17: long-lived agents with memory that split a big project into pieces and hand them to individual Devin instances, reachable via Slack, text, calls or scheduled triggers such as CI and Linear. It is on the radar because it is the coding-first answer to OpenAI's Dots and Anthropic's Duet, and it shifts the unit of work from a session to a standing manager. Coverage cites Cognition's own beta numbers (such as a studio going from about 50 to 1,900 PRs a week); treat those as vendor claims. Pricing and conflict handling between parallel agents were not specified.

### LangSmith Tool Gateway — a managed layer between agents and their MCP servers
LangChain put Tool Gateway into public beta on Nov 19. It sits between agents and MCP servers and centralizes auth, access rules and call records, exposing tool kits as standard Streamable HTTP MCP endpoints that work with clients like Claude Code and Cursor. It matters now because once agents run unattended, "which tool can call what, and who logged it" becomes the control point. Docs list it on Plus and Enterprise plans and note there are no usage dashboards yet.

### United Airlines — blocks unauthorized third-party AI agents from booking flights
United announced on Nov 11 that AI agents acting for travelers, directly or via agencies and aggregators, may not complete bookings, citing security, privacy and regulatory concerns. Agents can still search and show United flights. It is on the radar as an early case of a large merchant saying no to agent-driven checkout, which is a design constraint for anyone building purchasing agents. Reports say pre-Nov 11 agent bookings will be honored.
