# Daily Dev Digest — 2026-11-11

> Theme: Small and specific beats big and general — a decision model, a web-standards skill pack, and a driver pulled offline.

## Picks

### Strands Decider — a decision model that replaced Sonnet for ticket labeling at Amazon
Not a text generator: given a state and a question with options, it returns a probability per option plus a confidence score. The post says Amazon swapped Claude Sonnet 4.6 for the Gemma 4-based E4B build to label internal tickets into 20 categories. Reported per-ticket cost is about $0.0005 vs. $0.0222, and average call time 897 ms vs. 4,215 ms. The post gives no accuracy figures, all numbers are the authors' own, and it does not state a license for the repo.

### Modern Web Guidance — Chrome's skill pack to keep coding agents current on the web platform
A CLI and skills set from the GoogleChrome org, described as stewarded by the Chrome, Edge, Firefox and MDN teams. It feeds curated guidance and browser-compatibility data into the agent's context, with `search`, `retrieve` and `legacy-scan` commands. The README lists 250 web features and 203 use cases, and the repo ships plugin manifests for several agent tools. Apache-2.0. It's on the radar because agents tend to write dated web code, and this comes from the browser vendors themselves.

### Vino — a Rust DisplayLink driver that went offline after a Synaptics letter
A clean-room, in-kernel Rust DRM driver for DisplayLink DL3 USB docks such as the Dell D6000, written partly with Claude Code and tested so far on that dock. Phoronix reports the repo is no longer public, with Synaptics apparently using legal threats; secondary outlets cite a patent letter. No Synaptics statement or court filing turned up, so treat the details as unconfirmed. Worth watching as a test case for AI-assisted reverse-engineered drivers.
