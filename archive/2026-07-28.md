# Daily Dev Digest — 2026-07-28

> Theme: Agents stop visiting your environment and move into it — your browser session, your team chat, your docs, your own hardware.

## Picks

### ego-lite — a browser that hands your logged-in session to a coding agent
Most agent browser automation starts from a cold, empty profile, which is why half the tasks die at a login wall. ego-lite inverts that: it offers to migrate your Chrome data on first launch, so the agent inherits your cookies, extensions and bookmarks while working in its own Space instead of stealing your tabs. It hit the top of GitHub trending this week off the back of a benchmark claiming it beat Vercel's agent-browser on four automation tasks with less time and fewer tokens.

### Buzz — Block's Nostr-based workspace where agents are first-class members
Jack Dorsey's Block open-sourced a self-hostable workspace that fuses team chat, git hosting and agents into one surface, Apache 2.0, with a Nostr relay in Rust underneath. The interesting part isn't the Slack-plus-GitHub pitch — it's that agents get their own cryptographic keys and channel memberships, so a patch or a review approval is a signed event in an audit trail rather than an anonymous bot action. Model-agnostic by design: Claude Code, Codex and Block's own Goose all plug in.

### Kimi K3 — the largest open-weights model ever shipped
Moonshot AI put the 2.8T-parameter K3 weights on Hugging Face at 00:00 UTC on July 27, ungated, 96 shards totalling roughly 1.56 TB in MXFP4. Scale aside, the story for anyone considering it is the licence: it ships as a bespoke "Kimi K3 License" tagged `license:other`, with a revenue-triggered separate-agreement clause and a UI attribution mandate — read it before you build on it. Independent benchmarks were not available at release.

### OpenWiki — LangChain's CLI that writes docs for agents, not humans
It generates a structured `openwiki/` folder tuned for LLM context windows — headings, cross-references, summaries, plus Mermaid diagrams where a picture beats prose. The part that makes it more than another README generator is the shipped GitHub Action that opens a daily PR refreshing the docs as code changes, which turns documentation drift from a discipline problem into a merge queue item.
