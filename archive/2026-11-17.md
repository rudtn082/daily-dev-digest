# Daily Dev Digest — 2026-11-17

> Theme: Agents on every side — attackers automating intrusions, defenders plugging threat intel into their assistant, a self-hosted platform that lets agents only propose, and a cloud outage that came from a quiet gateway bug.

## Picks

### Google GTIG AI Threat Tracker — attackers automating vulnerability discovery and exploitation
Per BleepingComputer's write-up of Google Threat Intelligence Group's latest tracker, attackers used LLM frameworks to automate vulnerability discovery and exploitation with no human in the loop for the first time last quarter. Named frameworks include ARTEX, CAIRN, CyberStrikeAI and HexStrike AI; GTIG also describes suspected North Korean actors using Claude Code to deliver malware. On the radar because Google projects unsophisticated, mostly-agent attacks within about three months and sophisticated autonomous ones within about six. Those are Google's projections, not measurements.

### VirusTotal connector for Claude — threat-intel lookups over MCP
A VirusTotal threat intelligence connector lets Claude pull file, URL, domain and IP reports through MCP, with browser OAuth and no personal API key. Lookups and submissions are separate: uploads happen only on explicit request, and the service checks the file hash first. On the radar because it is a concrete defender-side counterpart to the attacker tooling above. Caveats from the write-up: standard submissions are shared with VirusTotal's community and partners, full URLs are exposed, and zero detections do not prove safety. Free tier is 60 queries/minute and 1,000/day; hosted chat workflows are not yet verified.

### Sutra-OS — self-hosted ontology platform where AI agents can only propose
Open-source (AGPL-3.0-or-later) Show HN project that models data as typed objects, links and actions, where actions are the only write path and the server validates every change. Changes are staged as proposals, AI agents can only propose, values keep lineage back to their source, and both model and data can branch. On the radar because it bakes "agents can't write directly" into the data layer. It is beta and, per the page, a one-person effort seeking maintainers; I did not test it.

### Microsoft 365 outage post-mortem — a months-old gateway bug, load-tested on weaker hardware
Microsoft says the Nov 12–13 global outage (Outlook, Exchange Online, Teams, Copilot) came from a bug introduced in a July update to networking gateway servers. Load tests ran on weaker hardware than production and missed it; about 14% of gateway capacity was already offline, and Teams failover traffic tipped it over. On the radar because it is a clean example of a test environment that doesn't match production. A final post-incident report is still expected, so details may change.
