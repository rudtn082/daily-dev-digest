# Daily Dev Digest — 2026-09-28

> Theme: Agents leave the chat box — onto a canvas, into a workflow, onto your timeline.

## Picks

### Drawgent — a coding agent that works on a live Excalidraw canvas
Connects your own Claude Code, Codex or opencode install to an Excalidraw whiteboard through an ACP bridge. You chat or leave AGENT: notes on the canvas, and the agent edits the diagram live. It surfaced as a Show HN this week — a concrete try at giving agents a spatial work surface instead of a scrolling wall of text.

### AgentRun — a DSL that turns repeatable agent work into workflows
Open-source workflow DSL from Parcha, written as JSON or a TypeScript builder with Zod contracts. Workflows can call other workflows, map work in parallel and run bounded loops, with tool calls and code mixed in and agents used only where a step needs investigation. It's on the radar as a Show HN and part of the shift from "let the agent figure it out" to structured, permissioned agent steps.

### Concat — an open-source CapCut replacement with an MCP API
Native Rust video editor for macOS, Windows, Linux and Android; captions, speech and background removal run locally and it exposes JSON-RPC, gRPC and MCP so scripts and agents can cut video too. It trended as a Show HN about a week ago. Still beta, per its own README.
