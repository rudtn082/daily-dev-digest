# Daily Dev Digest — 2026-10-27

> Theme: Smaller, closer to the metal — a local-first desktop AI app, a process CLI agents can parse, and a trillion-parameter open-weight model waiting on its weights.

## Picks

### Hob — an open-source desktop app that runs open-weight models on your own machine
Hob picks an open-weight model (it names Gemma and gpt-oss) that fits your hardware, sets it up, and works offline on Mac, Windows and Linux, with PDF filling and document work as the headline tasks. It's on the radar because a Show HN pitching it as an on-device alternative to Claude Cowork and ChatGPT drew 113 points on the HN digest we saw. The README is MIT-licensed but light on architecture, and commenters questioned how far it scales beyond basic tasks.

### proc — a process and port CLI built so agents can parse it
`proc free :3000` replaces the `lsof | xargs | kill` pipeline, and commands target a process by port, PID, name or path. It's interesting because the agent ergonomics are deliberate: `--json` output, fixed exit codes (0 ok, 1 error, 2 not found, 3 permission denied, 4 invalid input), `--dry-run`, and an agent skill for Claude Code, Codex, Cursor and Gemini CLI. MIT-licensed, installable via Homebrew, npm, cargo, Scoop, Nix or Docker. Destructive commands ask for confirmation, so check what your agent is allowed to auto-approve.

### Mistral Large 4 — a ~1T-parameter multimodal MoE whose weights are due by month's end
Mistral's October 6 post describes about 1 trillion parameters with 52B active per token, image and text input, and a public preview API at $1.36 per million input and $4.18 per million output tokens. It matters because Mistral says the weights drop at the end of October, which puts a European open-weight frontier-class model on the calendar this week. The post doesn't state a license, and the weights aren't out yet, so don't plan around them until they ship.
