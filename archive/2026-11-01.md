# Daily Dev Digest — 2026-11-01

> Theme: Tiny models and big swarms — what happens when you shrink the network to 512 bytes, or let fifty agents loose in a world.

## Picks

### bootgpt — a language model that lives in a boot sector
A 512-byte hand-written assembly boot sector loads an 11.5 KB int8 character-level model from the next 23 disk sectors and prints fake Linux kernel boot logs on a bare 386 in real mode, with no OS. The training script simulates the exact integer math of the assembly, and the README says outputs match character for character. It is a toy (8 characters of context, one hidden layer), but a clean demonstration of how little an LM needs. MIT licensed.

### YC Labs agent swarms in Minecraft and Mindustry — what 50 agents do with three hours
YC Labs, with Olam Labs, ran 50 GPT-6.1 Sol agents in a survival world told to "build a thriving civilization", and 10-vs-10 Bed Wars games between Claude Opus 5.5 and GPT-6.1 Sol agents. They report an informal leader emerging, invented bureaucracy, growing caution after a deadly first night (22 of 34 deaths), and GPT agents winning 6 of 9 Bed Wars games. The harness is built on the Pi agent loop and Mineflayer. Worth reading for the failure modes, which resemble overcautious coding agents; the Mindustry section was not reviewed for this entry.

### Simantic — firmware simulation so agents can test code without hardware (Launch HN)
YC F26 startup from former Neuralink and Tesla firmware engineers. It offers virtual devboards via a single API call, a CI step that runs firmware against a simulated MCU on every commit, and an AI reviewer that uses the simulator as its check. They started on Renode, then wrote their own Rust engine for timing accuracy. Supports some STM32, ESP32 and RP2040 parts; no analog co-simulation yet, and the promised silicon-vs-simulation accuracy report is not published. Vendor claims, not verified.

### LFM3 — Liquid AI's six open-weight 2B-class models
First open-weight release of Liquid's new generation: text (1.7B), vision, audio, omni and two "decision" models that return calibrated answers rather than text, with 256K context on the text model. The 1.7B model fits in about 1 GB at 4-bit, aimed at on-device use. Benchmarks are Liquid's own; check the license (LFM Open License v1.0 for the text model) before commercial use.
