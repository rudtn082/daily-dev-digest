# Daily Dev Digest — 2026-10-06

> Theme: Local inference gets serious, and models start answering in probabilities instead of prose.

## Picks

### ds4 (DwarfStar 4) — a C inference engine for running frontier-class open models on your own box
MIT-licensed engine that targets DeepSeek V4/V4.1 Flash, GLM 5.x and Qwen 3.8 Flash Next on Apple Silicon (64GB+), NVIDIA CUDA and AMD ROCm. It leans on asymmetric 2-bit quantization of routed experts and can stream the KV cache to SSD for long contexts, with a CLI, an API server and a native agent. It's on the radar because it hit the Hacker News front page this week, and because it comes from Redis creator Salvatore Sanfilippo, which gives the "local, no remote API" pitch some weight.

### Clef and Clef-flash — Cloudflare's open-weight decision models
27B and 9B models, post-trained from Qwen bases, that never write text: you hand them a state (text, JSON, images or video) plus typed questions, and they return a probability for every allowed answer in a single forward pass. Weights are Apache 2.0 on Hugging Face and hosted on Workers AI. Amazon's Strands Decider 2B, a 2B decision model with open weights and training data, landed the same day. Together they suggest a new slot in the agent stack: cheap, calibrated routing and branching decisions instead of parsing a chat model's output.

### universal-modder — skills and tools that let Claude Code mod almost any PC game
A Python repo pairing agent skills with a fal MCP server, aimed at pointing Claude Code at a game and having it do recon, reverse engineering and asset generation. It sat at the top of GitHub's daily trending list on October 5. It's a vivid example of the skills-plus-MCP pattern moving from developer chores into a hobbyist domain.
