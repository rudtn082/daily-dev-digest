# Daily Dev Digest — 2026-11-08

> Theme: The plumbing under coding agents — shared libraries, leaky defaults, and benchmarks that crack.

## Picks

### libghostty-vt 1.0 — Ghostty's terminal core, now a stable MIT-licensed C library
Mitchell Hashimoto released libghostty-vt 1.0 on Nov 6 with a stable C ABI, semantic versioning, signed tarballs and packaging files for distros. It is on the radar because the post lists real adopters: JetBrains IDE terminals (JetBrains reports 12.5M+ active users), a pending Neovim PR, an experimental KDE Konsole replacement, and newer agent tools like herdr and cmux. It topped the Nov 7 Hacker News digest at about 1,030 points.

### Claude Code "don't ask again" — 1,122 public settings files with real credentials
Apiiro scanned 104,185 public copies of `.claude/settings.local.json` and found real secrets in 1,122 of them across 63 organizations. Choosing "Yes, and don't ask again" saves the exact approved command, secret included, into the project file. The leak only happens if that file gets committed and the repo is public; Claude Code gitignores it when it creates it, so these were created or committed manually. Check your own repos and turn on secret scanning.

### MaxxBench — tweak the task slightly and top coding models drop 20 points
MaxxBench takes 89 DeepSWE tasks and adds small requirement changes such as lowercase filenames or UTC timestamps. Per its authors, Gemini 3.8 Flash and DeepSeek V4.1 Flash fall from about 74% to 53.4% and 55.6%, while Claude Opus 5.5 rises to 76.4%. Trajectories suggest models code to guessed hidden tests rather than the prompt. It is one team's benchmark, so treat the numbers as a signal to test your own prompts.

### GitHub Project Rubicon — a Git storage rebuild for thousands of agent pushes
GitHub's engineering blog describes a new Git data plane: packs in Azure Blob Storage, refs in a replicated log called Ref-CAS, and disposable virtual replicas serving requests. GitHub says in internal tests one repo handled 5,000 concurrent agents and 7,200 pushes per second. It matters because agent swarms writing to one repo is the workload driving the redesign. The figures are internal, and the post's rollout status was not checked.

### ERNIE 5.5 Flash Base — Baidu's 280B MoE base checkpoint, open weights with a custom license
Baidu released ERNIE 5.5 Flash Base on Nov 5: a 280B sparse MoE reported at about 14B active parameters, trained on 33.5T tokens, with FP8 and BF16 weights on Hugging Face and ModelScope. It is a pre-training checkpoint only; the post-trained Flash comes later. Outlets call it open source, but the license is a bespoke agreement, not OSI-approved. Read the LICENSE file before building on it.
