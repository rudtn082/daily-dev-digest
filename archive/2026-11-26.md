# Daily Dev Digest — 2026-11-26

> Theme: Old code, fresh exploits

## Picks

### Hex.pm RCE — a CVSS 10.0 parser flaw reportedly used to compromise six registry servers
The Hacker News (Nov 25) reports that an unauthenticated request to the Elixir/Erlang package registry reached a body parser that ran before authentication (CVE-2026-129514, CVSS 10.0), and that attackers used it to run commands on six servers, with account data and private packages potentially exposed. It is on the radar because a package registry is the root of trust for every project that installs from it. I could not corroborate the incident in a second source and could not load the article itself, so treat the details as one outlet's report; watch Hex.pm's own channels.

### Idunno.AntiCsrf — a legacy ASP.NET anti-CSRF library with a 9.3 unauthenticated RCE
Per The Hacker News (Nov 23), researchers are telling users to stop using this library: CVE-2026-131914, CVSS 9.3, with Mandiant rating exploitability "High", and the headline says it is being exploited. It is on the radar because the flaw sits in a security helper that many older ASP.NET apps still carry as a dependency. Check your dependency tree for it; I did not verify patch status.

### Microsoft agent-framework on PyPI — two poisoned releases steal cloud and CI credentials
Versions 1.26.1 and 1.26.2 of Microsoft's Python `agent-framework` were published on Nov 17, 33 minutes apart, and later quarantined by PyPI. Reports say the code ran at Python startup through a `.pth` file and went after Azure, Azure DevOps and GitHub Actions credentials; 1.26.0 is described as the last clean release. It is on the radar because the target was an AI agent SDK running in build pipelines. Reports disagree on how the attacker got publish access. If you installed either version, treat the machine as compromised.
