# Daily Dev Digest — 2026-11-03

> Theme: Agents that learn from their own runs, and video models that plan before they render.

## Picks

### TokenEconomizer — an external controller that cuts what coding agents spend
A paper (Ion Stoica, Jianfeng Gao and co-authors) treats Claude Code, Codex or Copilot CLI as a black box and learns from completed tasks in the same repo. It injects short repo-specific "micro-skills", prunes tools unlikely to be used, and sets a turn budget when the agent loops. On SWE-Bench (277 tasks) the authors report mean cost down 18.4–30.9% with pass@1 up in 4 of 5 settings. Numbers are the paper's own, and the task streams are related-but-independent fixes, not real user sessions. It matters because token bills are now the main friction in daily agent use.

### Harness² — improving an agent's harness recursively, without a verifier
Google Cloud AI Research proposes editing the prompts, memory, skills, tools and orchestration around a frozen LLM, keeping only edits supported by behavioral differences against a reference run. The paper reports up to 11.5 points of one-step gain on WorkBuddy-Bench (GLM-5 under OpenCode, 64.2 to 75.7). It is on the radar because it shifts the lever from the model to the scaffolding, and it appears on Hugging Face's trending papers list. Self-reported results; no ground-truth verifier is needed, which is the interesting claim.

### Hy-Nomas — Tencent's interactive world-generation model
A video world model that uses causal attention and structured conditioning to generate multi-turn video segments you steer with text and camera control. Paper published October 27, with a GitHub repo under Tencent-Hunyuan. It was trending on Hugging Face with 123 upvotes at time of check. Worth a look if you follow "world model" work that you can actually prompt turn by turn; I did not verify the license or weights status.

### SenseNova-6.8-Code2Video — a 27B model that programs each shot instead of generating pixels
SenseTime's open-weight model writes code for each shot, revises it, renders frames and critiques its own output. Weights hit Hugging Face on October 27 (27B, hybrid Qwen3.5 architecture), with Docker examples for LightLLM, vLLM and SGLang and community GGUF quants already out. It matters as a controllable, inspectable alternative to pixel-level video generators. No benchmarks or license were stated in the coverage I read.
