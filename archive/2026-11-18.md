# Daily Dev Digest — 2026-11-18

> Theme: The agent bill and the agent's homework — tools that cut coding-agent cost, grade the skills you hand them, run them as a daemon, and a default model swap that quietly costs 15x.

## Picks

### TokenEconomizer — Microsoft's cost-control plugin for coding agents
MIT-licensed project from Microsoft (listed with UC Berkeley in a Nov 16 roundup) that makes coding agents cheaper to run in repos you use often, without changing the agent. It learns from past sessions: repeated repo facts become "micro-skills" stated up front once three sessions confirm them, unused tools get pruned, and a judge model can nudge an agent stuck in a failure loop. On the radar because cost, not capability, is the complaint of the week. Full plugin support for Claude Code, Codex, GitHub Copilot CLI and Pi; others are experimental. I did not measure the savings.

### SkillEvaluator — NVIDIA's linter and A/B test for agent skills
Apache-2.0 tool (experimental) that checks agent skills and plugins in three tiers: validation (safety, format, harness compatibility), deduplication against itself and other skills, and live agent runs comparing with and without the skill in a sandbox. Outputs a 0–100 static quality score, security findings and CI gates. On the radar because skills are being installed like packages with little vetting, and this is an attempt at a test suite for them. Static score covers quality only; the live eval needs provider access and Docker.

### agentproto — an open TypeScript runtime that keeps coding agents running in the background
TypeScript project whose daemon runs agent sessions and exposes their tools over CLI, HTTP, MCP and SDK. The Nov 17 release adds per-account circuit breakers that move a session to the next healthy account after a usage cap, stale-CI-event filtering so outdated PR failures don't wake anyone, and live browser-stream relay. On the radar because usage-cap failover and wake-on-event are exactly the unglamorous problems of long-running agents. Release notes only; I did not run it and its maturity is unknown.

### Browser Use 1.0.6 — the default model is now 15x the price
Release notes say `Agent(task)` and `ChatBrowserUse()` now default to `bu-4.0` instead of `bu-fast`: $1.80/$9.00 per 1M input/output tokens versus $0.12/$0.60, at higher default reasoning. One short test task went from $0.0014 to $0.022 per the notes. Pass `llm='bu-fast'` to keep the old behavior. On the radar as a reminder to pin your model explicitly before upgrading an agent library.
