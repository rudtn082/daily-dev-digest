# Daily Dev Digest — 2026-11-04

> Theme: Giving agents better ground to stand on — and noticing what installs itself around them.

## Picks

### Auto-Ontology — NVIDIA's open context layer for agents querying enterprise data
An Apache-2.0 service that sits next to your databases, compiles their metadata into an ontology (business terms mapped to columns, reviewed SQL for measures, table relationships) and lets agents answer through it over MCP, agent skills or REST. People review and certify definitions in a web UI, and the agent checks whether a question is answerable before querying and returns the SQL with each answer. It is on the radar as a concrete take on "fewer wrong answers" for text-to-SQL agents. The accuracy claim is the project's own framing; evals live in a companion repo, and defaults point at NVIDIA NIM endpoints.

### Postman auto-installs AI agent plugins — a GitHub issue worth reading
A user report on Postman's support repo (desktop app 12.33.4, macOS) says opening the app installed Codex and Claude Code plugins plus a CLI, edited the Codex config, and added a SessionStart hook that nudges the agent toward a Postman skill. Others report similar behavior on later versions and in Cursor and Copilot settings. Postman replied on Nov 3 that the bundling is disclosed on the download page and in the update flow, and said it will make opt-in clearer and review hook approval. It matters because agent config dirs are now a place where ordinary apps write. Check your own `~/.codex` and `~/.claude`. Allegations are from the thread, not independently verified.

### Sparks of Weight-Space Programming — can a model read a network's weights?
A paper (Takehi, Teoh, Zhang, Khattab) claims a frontier model can infer what a policy network was trained on just from its raw weights, and even edit weights without a training loop. Simon Willison reran the no-tools reading task: Kimi K3.1 Pro identified Breakout, and a local Qwen 3.8 27B got Breakout and Pong but missed Freeway, taking close to an hour per run. He is impressed but skeptical of the hype; Matthew Honnibal calls the editing claims misleading. It is on the radar because it was near the top of HN, and because a laptop-sized model can even attempt it.

### Hue — simulated worlds to test agents before production
A YC-backed platform that generates stateful fake copies of the apps an agent touches (Gmail, Slack, Notion, Salesforce, GitHub and others), runs your agent against them in your own process, and scores runs across agent versions. It can also rebuild a world from traces and works with OpenTelemetry-based tooling. It is on the radar because agent evals keep running into "don't test against real inboxes". Capabilities and compliance claims are from the vendor's page; I did not try it.
