# Daily Dev Digest — 2026-11-16

> Theme: Trust you didn't know you were extending — a blocker's picker that took orders from any site, std-library code that safe Rust can break, short links anyone can re-register, and database branches for agent sandboxes.

## Picks

### uBlock Origin (Firefox) universal XSS — one click on a malicious site could run JavaScript on any domain
A write-up describes a flaw in the Firefox build: a malicious site can learn the extension's random UUID, embed the element picker in an invisible iframe, and use it to add a trusted filter that injects script into any site. The author says it is now patched and notes the MV3 build (uBO Lite) had a milder variant; the post names no patched version, and credits the discovery to an AI model. On the radar because browser extensions with broad page access are exactly where one trusted-message bug becomes every-site compromise. Check your extension is up to date.

### Hyenas — Microsoft's FORGE Lab finds soundness bugs in Rust's standard library
Microsoft's FORGE Lab used an AI-powered scanner called Hyenas on Rust's core and std libraries and found cases where safe code can trigger undefined behavior. The write-up groups them into three kinds of misplaced trust: assuming code won't panic, assuming user-provided implementations are correct, and assuming the underlying system behaves. One fix reportedly ships in Rust 1.100 (allocators may no longer unwind). On the radar because it shows AI-assisted auditing finding bugs in the most-reviewed unsafe code around. The post gives no bug count and I did not confirm the status of the other fixes.

### Bitly dead links — strangers re-registered expired short links from old Burger King, McDonald's and Trump tweets
Per a ransomnews.com report, expired Bitly short links from years-old tweets were re-registered by others and now redirect to unrelated pages. Of 97 Bitly links in Trump's 2009-2013 tweets, 57 reportedly no longer point to the original, seven to destinations never intended. No accounts were hacked; the link endings became available again. On the radar because any short link you published is a dependency you don't control. The report includes no statement from Bitly.

### db-branch — instant MySQL and PostgreSQL branches via ZFS clones
Open-source (Apache-2.0, self-hosted) tool that creates copy-on-write database branches using ZFS clones, each with its own database server, with reset, checkpoint and expire commands. It ships a CLI, REST API, web console and MCP server. On the radar because per-agent and per-PR databases need to be cheap and disposable. It appears to require ZFS; an HN thread left open whether branches can merge back, and a commenter pointed to postgres.ai Database Lab as an existing alternative.
