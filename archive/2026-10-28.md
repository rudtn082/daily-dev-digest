# Daily Dev Digest — 2026-10-28

> Theme: Plumbing you build on — a terminal, an operating system and a GPU scheduler, all shipped or opened up this month.

## Picks

### Ghostty 1.4 — the GPU terminal emulator's biggest release in a while
Ghostty 1.4.0 landed October 27 with macOS 27 support, completed Kitty graphics (animation and relative placement), scrollback compression with a default limit raised to 50 MB, and a new EGL-based renderer on GTK that keeps text sharp at fractional scaling. The release notes also claim 25–55% higher pty I/O throughput on macOS and add `ghostty +ssh`, a wrapper that prepares remote hosts. It's on the radar because the release notes showed up on a Hacker News front-page snapshot with 841 points.

### Moxnox 1.0 — a hobby OS with NT-style syscalls and a Unix userland
Mark Harmstone, known for the WinBtrfs driver, released Moxnox 1.0 on October 27. It pairs Windows NT-inspired system calls and PE executables with Unix filesystem layout and ported tools (Bash, Coreutils, GCC, LLVM, Git, Python, Rust, OpenSSH), on x86-64 and ARM64 including Raspberry Pi 5. It's a curiosity worth a look: self-hosting for its own components, native Btrfs. The write-up says Btrfs is lightly tested, there's no desktop, multiuser or real security model, and it can't run Windows apps. We couldn't confirm the license from the article, so check the repo.

### NVIDIA Run:ai (open source) — GPU scheduling and fractioning for Kubernetes, now in the open
On October 13 NVIDIA said it is open-sourcing the full Run:ai platform under its DSX AI Factory Platform: KAI Scheduler (Apache 2.0, contributed to CNCF as a Sandbox project), a GPU Fractioning Operator, resource management for quotas, and a Workload Map contract. It matters to anyone sharing GPUs across teams, since this was previously a commercial product. Licenses vary by component, and the NGC community product needs NVIDIA's license terms and comes without enterprise support.
