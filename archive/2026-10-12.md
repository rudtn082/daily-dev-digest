# Daily Dev Digest — 2026-10-12

> Theme: Agents reach outward — onto the open web, onto your screen — plus a small open dataset that decodes what your phone's carrier is really doing.

## Picks

### Agent-Reach — one CLI that gives an agent eyes on the internet
An MIT-licensed command-line tool that lets agents like Claude Code and Cursor read and search Twitter/X, Reddit, YouTube, GitHub, Bilibili, Xiaohongshu, LinkedIn, RSS and plain web pages. It installs the upstream tool each platform needs, routes each channel through an ordered list of backends with fallback, and ships a doctor command that reports what works. It showed up in a GitHub daily trends report on Oct 10. The hard part of agent web access is scrapers breaking; swappable backends hide that churn. The README itself warns that cookie-based access can get accounts flagged, so use a secondary account.

### bigarrow — let your agent point at the button instead of describing it
A macOS-only Swift CLI that draws a click-through arrow with a text sign over any window, and never clicks, types or captures the screen. It finds controls by label (for example "Allow" in System Settings), self-expires, and ships a skill for Claude Code and Codex. It was a Show HN on Oct 10. Instead of "click the third toggle on the left", the agent shows you where, which is a safer human-in-the-loop than letting it drive the mouse.

### Carrier-Explode — iPhone, Pixel and Galaxy carrier settings, decoded
An open-source site that breaks carrier configuration shipped in iPhone, Pixel and Galaxy firmware into per-carrier APNs, VoLTE, Wi-Fi Calling and 5G support, with carrier and version comparison. It exposes a JSON API and a daily CC0 dataset. It was a Show HN on Oct 10. These settings are normally opaque blobs; a diffable, public dataset makes it possible to see what changed between builds.

### nanobot — a self-hosted personal agent you can read end to end
HKUDS's MIT-licensed Python agent framework with WebUI, terminal and chat-app front ends (Telegram, Discord, Slack and more), MCP, scheduled tasks, subagents, long-term memory and an OpenAI-compatible API. It appeared in the same Oct 10 trends report. The pitch is a small, readable core rather than a sprawling platform, though the README gives no size figures to verify that. A useful reference if you want your own agent without adopting a giant framework.
