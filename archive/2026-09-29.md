# Daily Dev Digest — 2026-09-29

> Theme: Agents get boundaries, a real browser and an office to work in.

## Picks

### OpenAPPA — deterministic guardrails that don't break agents
MIT-licensed guardrail that sits outside the agent loop and tracks how data flows across tool calls, labelling it by source, audience and trust level. Decisions come from a declarative `appa.toml` rather than pattern-matching, and blocked actions come with machine-readable remedy plans. It showed up in today's Hacker News AI digest, and its own numbers (89% task completion vs 90% for Claude's auto mode, all tested attacks blocked) are worth checking yourself.

### Univer — the office harness for AI agents
Apache-2.0 SDK for embedding spreadsheets, docs, slides and PDFs, now pitched as an "Office Harness for AI Agents". Agents inspect and edit content through structured APIs, check their work with screenshots and layout diagnostics, and hand changes to humans as isolated drafts to review and merge. It sat in the top-rising list of this week's agents radar — a bet that agents need a proper editing surface for office files, not just text output.

### BrowserSkill — Tencent's bridge to your real, logged-in browser
MIT-licensed CLI (`bsk`) plus Chromium extension that lets any shell-capable agent — Claude Code, Codex, Cursor, Pi and others — work in the Chrome or Edge profile you're already signed into. Tasks run in a separate visible Agent Window, and the CLI talks to the extension through a localhost-only daemon. It surfaced in this week's GitHub trending roundups — logged-in sessions are where agent browsing usually breaks, and this targets that directly.

### disktree — a treemap for finding what fills your disk
Rust + GPUI disk-usage analyzer that shows storage as an interactive treemap, with a mark-review-confirm delete flow and Git status overlays. It runs on Linux, macOS and Windows and is MIT-licensed. It made the GitHub trending list on Sep 26 — a plain, useful tool in a feed full of agent harnesses, and agent-heavy machines fill disks fast.
