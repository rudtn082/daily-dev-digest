# Daily Dev Digest — 2026-10-31

> Theme: Trust the toolchain less — a backdoored extension, and the open stacks moving AI infra off one vendor.

## Picks

### Claude Code for VS Code, backdoored on the Cursor Marketplace — check your extensions
Phorion reports that versions 2.1.312 and 2.1.313 of the official-looking Claude Code extension on the Cursor Marketplace carried injected code that runs as soon as Node loads the file. It adds an attacker SSH key, opens a reverse tunnel, installs persistence on macOS, Linux and Windows, and sends a recon beacon. Cursor has removed the versions; uninstalling alone does not clean up, so follow the advisory's removal steps. Phorion does not say how many hosts were hit.

### TorchTPU — native PyTorch on Google TPUs, open source
A Google and Meta collaboration, started mid-2025, that adds a native PyTorch backend for TPUs with eager-mode optimizations and torch.compile integration. TPUs were mostly a JAX and TensorFlow world; this is a serious attempt to make PyTorch code run there without a rewrite. Performance claims are the authors' own.

### llm-d 1.0 — distributed LLM inference in the CNCF Sandbox
A Kubernetes-native inference stack that works with vLLM and SGLang. The 1.0 adds multi-tenant flow control, zero-downtime upgrades of disaggregated deployments, and session-aware KV-cache routing, on GPUs and Google TPUs. Worth watching as the open answer to "how do we serve this at scale" alongside the cloud-vendor stacks.

### Sleep framework — Google Research on LLMs that consolidate memory offline
Proposes alternating a wake phase (fast short-term memory) with a sleep phase that moves knowledge into long-term low-rank MoE parameters and "dreams" synthetic training samples. Google reports near-zero forgetting in a continual-translation test and strong BABILong results up to 10M tokens. A research claim from the authors, not yet independently reproduced.
