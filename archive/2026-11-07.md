# Daily Dev Digest — 2026-11-07

> Theme: Smaller open models and local agents — and a coding model you can only rent.

## Picks

### Ripple-65B Preview — a 65B dense open-weight coding model under Apache 2.0
Ricursive Intelligence released Ripple-65B Preview on Nov 4 as three checkpoints (instruction-tuned BF16, NVFP4, and a BF16 base), all Apache 2.0. It is on the radar because it is a dense 65B, not a giant MoE, so it is a size people can actually host. Its headline Terminal-Bench score is vendor-reported, and the model card's 1M-token context does not match the 16,384-token window on the hosted OpenRouter endpoint. Verify both before depending on it.

### SWE-2 Flash — Cognition's cheaper, faster coding model, free in Devin through Nov 30
Cognition launched SWE-2 Flash on Nov 4 inside Devin Desktop and Devin CLI. Per Cognition it is one-fifth the price of SWE-2 and three times faster, and it is listed as free through 11/30. The catch is that it has no public weights and no public API; it only runs inside Cognition's products. Benchmarks are mixed and company-reported, with Flash ahead on FrontierCode 2.0 and SWE-2 ahead on Terminal-Bench 4.0 and DeepSWE 1.1.

### Local Code — Draw Things' open-source agent app that runs fully on your Mac
Draw Things announced Local Code on Oct 28: a macOS agent app that needs no API key, sign-in or external MCP server, and sends no prompts or files to a cloud provider. It ships with a model selector covering DeepSeek 4.1 Flash 1017 (for Macs with 64 GiB+ RAM) down to Qwen 3.8 27B (16 GiB+). It showed up again in this week's Mac software roundups. The code is on GitHub, but the announcement names no license, and the "no loss of intelligence" and benchmark claims are Draw Things' own.

### Inkling 2 Small — Thinking Machines' MoE with 1M context, weights promised
Thinking Machines Lab released Inkling 2 Small on Nov 5: a mixture-of-experts model with image input and a 1M-token context. Full weights are promised under Apache 2.0 after external safety testing, so they were not downloadable at last check. It matters because Cognition says SWE-2 Flash is built on the earlier Inkling-Small, which shows how an open base turns into a closed product.
