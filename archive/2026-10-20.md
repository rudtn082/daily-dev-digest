# Daily Dev Digest — 2026-10-20

> Theme: Trust, but check: a git hook that quizzes you, a small model with the writing tics trained out, and local AI you can size up before you buy.

## Picks

### Nemotron 3.5 — Nvidia's open-weight agent models for the enterprise and for AI PCs
Nvidia released Nemotron 3.5 Super VL (120B parameters, for enterprise agents) and Nemotron 3.5 Bolt 74B-A9B 24GB (for local agentic work on AI PCs and DGX Spark workstations); a smaller Bolt E4B is due later this month. Nvidia says Super VL matches Nemotron 3 Ultra on instruction-following and tool-use with fewer parameters — its own claim, not independently verified. It matters because it is another big-vendor push for agent models that run on your own hardware; the coverage names no license, so check the model cards.

### Sphinx — a Git hook that quizzes you on your AI's code before you push
Sphinx reads your diff and asks what happens when things go wrong; answer correctly and the push continues, otherwise it explains why and asks again. It works with Codex, Claude Code, Cursor, OpenCode and Pi, uses OpenRouter or any OpenAI-compatible endpoint, is MIT licensed, and has a logged `sphinx yolo` escape hatch. It matters because it targets the real failure of agent-heavy workflows: shipping code nobody on the team actually understood. It sat near the top of Show HN today.

### Qwen3-4B deslop — a small model with the AI writing tics trained out
Erik Markus Kannike distilled Qwen3-4B-Instruct-2507 with a LoRA adapter plus a sign flip on four MLP neurons, on an M2 MacBook Air. By his regex-based detector, the slop score fell from 121 to 12.5 per 1000 words and em dashes to zero, with factual answers and task fit intact. Caveats from the author: flat voice, still invents names, short English prose only, no blind reader test, and no license stated for the weights. It matters as a cheap, reproducible recipe for changing a model's style by editing weights instead of prompting.

### Llmspeed — feel how fast a local LLM runs before you buy the hardware
A site where you pick a GPU, Mac or CPU-only setup, or a model, and see estimated speed for it. Figures come partly from community benchmarks (r/LocalLLaMA, localscore.ai) and partly derived or projected from specs, so treat them as estimates. It matters because the "will this card run this model usably?" question is the biggest gap before a local-AI purchase, and this answers it in one page. It was the top-scoring Show HN item in the snapshot.
