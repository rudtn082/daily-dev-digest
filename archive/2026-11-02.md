# Daily Dev Digest — 2026-11-02

> Theme: Lean replacements — a diff tool, a browser, an API client and a camera app, each built to be lighter than what it stands in for.

## Picks

### OmniDiff — a syntax-aware, move-aware diff tool in Rust
Parses source files in 25 languages with tree-sitter so it highlights only the changed parts of a line and shows moved code as moved. It also diffs some binary formats by content (fonts glyph by glyph, PDFs page by page), and works as a `git difftool`, a `GIT_EXTERNAL_DIFF` backend, or with jj. It is on the radar because it was one of the higher-scoring Show HN posts of the day. AGPL v3; the repo says it does not accept contributions right now and discloses substantial AI assistance. Accuracy claims are the author's own.

### Lightpanda — a headless browser written from scratch in Zig, aimed at agents
Not a Chromium fork: no rendering engine, but a CDP server (Puppeteer-style connections) plus WebDriver BiDi, an MCP server and Markdown/HTML dump modes. The README claims about 16x less memory and 9x faster than Chromium on a 100-page run; those are the project's own benchmarks. It showed up on GitHub trending today, and it matters because browser use is an agent bottleneck. Linux binaries need glibc, Windows goes through WSL2, and the license is AGPL-3.0.

### Ghostman — a terminal API client and webhook inspector
A Python/Textual TUI positioned as a lightweight alternative to Postman and Insomnia. It shows DNS and time-to-first-byte latency, formats JSON, has a built-in webhook listener on port 9090, and saves requests as plain files you can commit to Git. Very new (v0.1.0 per the repo) and MIT licensed. Its memory comparisons against Postman are its own claims.

### Outcrop — point your phone at a landscape and read its geology
From the team behind Flyover Country. The camera view overlays a geologic map on the terrain, names the rock at screen center, and gives age, composition and a rock column where data exists. A globe view animates where the rock formed using PALEOMAP plate reconstructions. Bedrock and faults come from Macrostrat worldwide. Free on Android; iPhone is in TestFlight beta. Offline areas can be saved.
