# Daily Dev Digest — 2026-10-19

> Theme: Small, fast and local: a multimodal embedder for your phone, a Rust type checker at Google scale, and diagrams as plain HTML.

## Picks

### EmbeddingGemma 2 — Google's open multimodal embedder sized for on-device use
One shared embedding space for text, code, images, video and audio, under Apache 2.0. Google says the full multimodal setup needs about 567 MB of RAM when quantized (text-only about 191 MB) on a Pixel 11 Pro — those are Google's own figures. It matters because local multimodal search no longer needs a server-side embedding service, and it ships with wide runtime support (llama.cpp, Ollama, MLX, transformers.js, LM Studio and more).

### Pyrefly — Google swaps its internal Python type checker for Meta's Rust one
Google adopted Pyrefly across its Python monorepo, replacing Pytype, which was tied to bytecode analysis and stops at Python 3.12. Google reports an order-of-magnitude speedup and large cuts in incremental-rebuild latency and peak compute — internal numbers, not independently measured. It matters as a rare large-scale proof that a Rust type checker can replace a long-lived in-house tool.

### diagram-design — an agent skill that writes editorial-style diagrams as one HTML+SVG file
Install it into Claude Code, Codex, Copilot, Cursor, Pi and other Agent Skills hosts; it produces 44-ish diagram types with no build step or JavaScript, can match your site's colors and fonts, and can redraw draw.io, Mermaid or Excalidraw files. MIT licensed. It is on the weekly GitHub trending list, a sign that agent skills for visual output are catching on beyond code.
