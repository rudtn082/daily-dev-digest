# Daily Dev Digest — 2026-09-27

> Theme: Agents move from demos to operations — who manages them, what they remember, where they run.

## Picks

### paperclip — an open-source app for managing agents at work
A control plane for the agents a team runs, pitched as the app everyone uses to manage them. It posted the biggest one-day star gain in the Sept 26 AI-trends roundup, a sign that "who supervises the agents" is now a product category of its own.

### hindsight — a persistent memory system for agents
Gives agents memory that carries learning across sessions instead of starting cold each run. It's on the radar because stateful agents are the recurring blocker for production deployments, and hindsight was second on the Sept 26 daily star-gain list.

### google/ax — Google's agentic orchestration runtime
An orchestration runtime for deploying autonomous agents, published under Google's own org. A major cloud vendor shipping open agent infrastructure raises the stakes for the smaller orchestration frameworks — it made the same trending list.

### ZCode — Z.ai's coding agent harness
Z.ai's coding agent harness, described by its authors as powerful, intelligent and extensible. It topped GitHub's Sept 26 daily trending list, which fits the wider pattern of model labs shipping their own harnesses next to their models.
