# Daily Dev Digest — 2026-11-27

> Theme: Patched, but still being hit

## Picks

### Drupal installer RCE (CVE-2026-132165) — a flaw that lets a remote attacker rerun the installer on a live site
Drupal shipped fixes on Nov 18 (11.3.22 and 10.6.22) for a core installer bug rated 18/25 on its risk scale. Per press coverage, an attacker can rerun the installer on an already-installed site, which can lead to code execution. It is on the radar because Drupal warned exploits could appear within hours or days, and advises blocking the installer even after updating. The advisory did not confirm active exploitation of this specific CVE as far as I could verify; a Nov 26 Hacker News headline claims takeover attempts are under way, but I could not load that article.

### Apache Roller XML-RPC deserialization (CVE-2026-129448) — unauthenticated RCE, CVSS 9.8, confirmed exploited
Apache says untrusted serialized data reaches Java deserialization in Roller's XML-RPC endpoint before authorization is checked, affecting 4.0.0 through 6.1.4. The ASF advisory states the issue is being actively exploited, and one source says a Python PoC has been public on GitHub since Sep 28. It is on the radar because a months-old public PoC plus confirmed exploitation turns this into a patch-now item for anyone still running a self-hosted Roller blog. Sources disagree on the exact fixed version (6.1.6 vs 6.1.7); check Apache's advisory.

### Check Point PHP2Shell campaign — chained attacks on unpatched Check Point gateways
Cybersecurity Dive reports a threat actor chained the PHP2Shell flaw with a privilege-escalation bug against unpatched Check Point Security Gateways, hitting about 25 servers globally, two reportedly tied to the US government. The activity is attributed to AI-assisted, China-nexus actors, though Check Point researchers are unsure whether that is a false flag. It is on the radar because the entry points were already-patched bugs on perimeter security gear. A Nov 26 Hacker News headline puts the count at 24 management servers; I could not reconcile the two reports.
