# Daily Dev Digest — 2026-10-03

> Theme: Hand-built and low-level — tools that go back to the metal, plus a cockpit for supervising agents from anywhere.

## Picks

### Paseo — an open-source cockpit for Claude Code, Codex, OpenCode and Pi
A local-first, self-hostable interface that wraps the coding agents you already run in a daemon/client design, with desktop, web and mobile clients. No telemetry, no forced login. It's on the radar because agent supervision is moving off the laptop: the pitch is monitoring runs from your phone while away from the desk.

### Rhun — a code editor written in assembly, with agent sessions beside the code
MIT-licensed editor for Windows, Linux and macOS with tabs, fuzzy search, optional Vim mode, a built-in terminal and Git diffs, and room for AI agent sessions. Its tagline is "AI does the heavy lifting, keep your code editor light." It hit the Hacker News front page as a deliberate counterweight to heavyweight, Electron-sized agent IDEs.

### kcc — a C17 compiler in ARM64 assembly, written as a ~1000-page literate book
An MIT-licensed compiler whose sources are literate `.weft` files, tangled into the assembly, scripts and Makefile. Per the README it compiles itself to byte-identical binaries, cross-compiles to x86-64, builds Lua, SQLite and DOOM, and can boot a Linux kernel. The author credits Claude as a co-author, which makes it a concrete data point on how far model-assisted systems work can go.

### OpenDLSS-NR — an open reimplementation of the DLSS 5 neural rendering network
A Vulkan (and WebGPU, in-browser) reimplementation that reconstructs the internal computations of the 71-block network in DLSS-NR build 310.8.0, down to how numbers are rounded. It was released in September and hit Hacker News this week. It matters as an independent, inspectable version of a closed, GPU-vendor-locked technique.
