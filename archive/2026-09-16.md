# Daily Dev Digest — 2026-09-16

> Theme: The price of a token, a review, and a GPU-hour — three projects that make AI cost something you can check.

## Picks

### Colibri — frontier MoE models on hardware you already own, experts streamed from disk
A pure-C, zero-dependency inference engine that treats VRAM, RAM, and storage as one tiered hierarchy: dense layers stay in RAM, routed experts stream from disk on demand. It runs nine families today, from OLMoE up to Kimi K3 (2.8T), including GLM-5.3-Flash and DeepSeek V4.1 Flash, with token-exact validation against transformers. The README is blunt that "speed is set by your disk" — its own table goes from ~6 tok/s on six RTX 5090s to ~1.8 tok/s on a 128 GB CPU desktop and a crawl on a 25 GB box. On the radar because it moves the question from "can I load this model" to "how many tokens per second is my SSD worth." Apache 2.0.

### Open Code Review — Alibaba's internal reviewer, with the deterministic parts taken away from the model
A CLI (`ocr`) that reads git diffs and posts line-level review comments, open-sourced from Alibaba's internal system. File selection, bundling related files, rule matching, and comment positioning are hard-coded pipeline steps; the LLM agent only handles judgment and context retrieval. The project reports about 1/9 the tokens of a general-purpose agent with better precision and F1 — its own numbers, so measure on your repo. Interesting as a design stance: take away from the model every step that doesn't need a model. Runs in GitHub Actions and GitLab CI, with plugins for Claude Code, Codex, and Cursor. Apache 2.0.

### Computable GPU Index — an open, reproducible price for an H100-hour
A USD-per-GPU-hour index for H100, H200, B200, and B300, computed from a fixed panel of providers' on-demand rates. Its method takes weighted votes and averages the central band, so no small group of providers can drag the number from the tails, and you can clone the repo and recompute any published value from the public record. Anonymous read-only API, no key. GPU pricing is mostly quoted by the people selling the GPUs; a number you can re-derive yourself is useful for budgets and contracts. Code Apache 2.0, data CC BY-NC 4.0.
