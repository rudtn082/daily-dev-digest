# Daily Dev Digest — 2026-11-09

> Theme: Where agents live — sandboxes, serving runtimes, memory formats, and CPU-only inference.

## Picks

### Agent Substrate + gVisor — Google donates an agent runtime and sandbox to the CNCF
Announced at KubeCon NA, both projects enter the CNCF at Sandbox level. Substrate keeps each agent session's state (filesystem, env, memory, network rules) as an "Actor" and snapshots it to tiered storage when idle, freeing the Kubernetes Pod. Google claims resume in under 500 ms; the figure is the vendor's own. The pitch: agents sit idle 90–95% of the time, so always-on Pods waste money and cold serverless starts are slow. The post does not state Substrate's license.

### XLA Serving Engine — "train in Python, serve in C++" for JAX models
Google open-sourced a C++ runtime that loads an exported XLA SavedModel (StableHLO) and serves it over gRPC without Python. Apache 2.0, with Docker images for CPU, GPU and TPU. Google reports 2–5x throughput over its best Python server on short requests, and says it already serves over 6M queries per second internally. It is aimed mostly at non-LLM models; the post itself points to vLLM or SGLang for long-context LLMs. PyTorch support is planned, not shipped.

### LoreKit's open agent-memory format — an "OpenTelemetry moment" for memory
Every agent tool stores memory in its own shape. This proposal sketches a shared record (frontmatter envelope + Markdown body) and five operations over MCP: write, read, list, search, archive. The author is explicit that it is early: no working group, no draft, open questions on address levels and default forgetting, and the spec should live somewhere neutral. Worth reading as a design discussion, not a standard.

### llama-modchip — a 284B MoE on a 64 GB CPU-only box
A patch set for llama.cpp with a custom low-bit format, AVX-512/NEON kernels and an n-gram speculative drafter. The README claims DeepSeek-V4-Flash in about 57 GiB and 9–15 tok/s decode on a Ryzen 9 9955HX. Caveats from the README: models need the patched build, headroom is near zero, and the quality scores come from the author's own eval. Apache 2.0. It's on the radar because it pushes "which model fits my machine" further down.
