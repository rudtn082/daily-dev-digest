# Daily Dev Digest — 2026-11-14

> Theme: Agent plumbing gets real — a local-first agent anyone can run, an editor consolidating on one harness, and an inference vendor's breach that spread through a cloud provider.

## Picks

### Nod — n8n Labs' open-source personal agent that runs on your own machine
Research preview for Mac and Windows, released Nov 10 under Apache 2.0 per n8n's own post. It works in a sandboxed browser environment, keeps memory and credentials on-device, and lets you pick the model; Nod itself is free, you pay your model provider. On the radar because local-first agents that touch your accounts are only credible if the credentials never leave your box. n8n says it is not production-ready, and one competitor post said it could not yet confirm the code was published, so check the repo.

### VS Code 1.146 — Local agent harness deprecated, Copilot harness becomes the path
VS Code's docs say the Local agent harness is deprecated and will be removed by February 2027; the Copilot harness, built on the Copilot SDK, is the default for new sessions. On the radar because extension and workflow authors who built on the Local harness now have roughly a quarter to migrate. I did not find the 1.146 release notes themselves; the Nov 12 release date comes from secondary coverage.

### Fireworks AI breach widens — second intrusion via a third-party cloud provider
Fireworks' Nov 9 bulletin update says attackers reached account and billing data and, for a limited set of customers, secrets, datasets and incomplete model weights, after a cloud provider hosting its R&D machines was compromised around Oct 23-24. The provider is unnamed; self-serve dataset uploads and downloads are disabled; Unit 42 is reported to be doing forensics. On the radar because it is a concrete reminder to rotate any secret or dataset you ever gave an AI vendor. Details on customer impact are from press reports; nothing after Nov 11 found.
