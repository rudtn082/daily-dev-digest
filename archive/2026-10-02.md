# Daily Dev Digest — 2026-10-02

> Theme: The plumbing around agents — a sandbox to contain them, a rig to organize them, a light runtime to feed them, and a notebook that runs.

## Picks

### OpenShell — NVIDIA's sandboxed runtime for autonomous agents
Apache-2.0 runtime that lets agents touch files, install packages and call APIs inside isolated sandboxes, with policies enforced at the kernel level. Agents never see real credentials; OpenShell injects them only for approved endpoints, and policy changes are checked before approval. It was at the top of GitHub's daily trending list today, which fits: as agents get more autonomy, containment is becoming its own product category.

### OpenRig — a harness that turns coding agents into a persistent team
Apache-2.0 tool that defines multi-agent topologies in YAML (pods, edges, continuity policies) and launches them with `rig up`, coordinating Claude Code, Codex and Pi sessions with roles, shared context and tracked work. It can adopt existing tmux sessions and snapshot or restore team state. It requires macOS or Linux, with Windows not yet supported. Also on GitHub trending today, as people move from one agent to several.

### Janus — a single Go binary that serves GGUF models over Vulkan
Show HN project: one executable wrapping llama.cpp with Vulkan (AMD, Intel, NVIDIA) or CPU fallback, exposing OpenAI-compatible endpoints, with model hot-swap and separation of `<think>` reasoning into `reasoning_content`. The appeal is zero dependencies and no CUDA lock-in for local inference.

### Ledge — Markdown notes whose code blocks run
Show HN project: a notebook app where shell, Python, SQL and other code blocks in plain Markdown files execute in place, locally or over SSH, with an MCP server so agents can read, search and edit notes. Apache-2.0, notes stay ordinary files. It popped on Show HN today as runbooks and agent-readable notes converge.
