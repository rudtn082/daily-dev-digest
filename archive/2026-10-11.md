# Daily Dev Digest — 2026-10-11

> Theme: Agents get new output formats — video and CAD from a prompt, a remote GPU over the wire — and a 1996 classic rewritten in Rust.

## Picks

### HyperFrames — write HTML, get a deterministic MP4, built for agents
HeyGen's Apache 2.0 framework turns HTML, CSS, media and seekable animations into MP4 using headless Chrome and FFmpeg. It ships installable skills that teach coding agents the loop of planning, writing HTML, animating, linting, previewing and rendering, and its CLI is non-interactive by default. It sits on this week's GitHub weekly trending list. Video as plain web code is something an agent can actually edit and diff.

### text-to-cad — CAD workflows for Claude Code, Codex, Cursor and friends
MIT-licensed plugin and skills library that lets agents generate 3D models from plain-language or image requests, run design-for-manufacturing checks and produce engineering drawings. Outputs include STEP, STL, 3MF, GLB, DXF, PDF drawings, G-code and robot description files (URDF, SRDF, SDF). It also appears on this week's GitHub weekly trending list. It pushes agents from screens into things you can manufacture.

### rGPU — a PyTorch device whose tensors live on a remote GPU
Show HN project that runs GPU work on a remote NVIDIA machine while the app stays on the client. It offers an opt-in `rgpu` PyTorch device and a CUDA shim for existing Linux CUDA programs. Caveat from the README: neither protocol authenticates or encrypts, so keep the server on localhost behind SSH and firewall the CUDA port. Handy idea for a laptop plus a GPU box, but treat it as an experiment.

### QUAKE·SRP — Quake ported to Rust, software-rendered in the browser
Show HN project: id Software's 1996 Quake, ported to Rust from its GPL source and rendered in software, no GPU needed. The page does not say how much of it is safe Rust or whether AI tools helped, so those details are unverified. It drew strong Hacker News interest this week as a fun, playable example of a classic codebase in a memory-safe language.
