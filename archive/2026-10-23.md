# Daily Dev Digest — 2026-10-23

> Theme: Local and durable — a laptop-sized coding model, a long-term-support database, and agents whose state survives a crash.

## Picks

### Flint — Recursive's open-weight coding model sized for a laptop
A mixture-of-experts coding model with about 40B total and roughly 2.5B active parameters, released October 21 under Apache 2.0 and runnable through Ollama, LM Studio, llama.cpp and vLLM. It's on the radar because Recursive says its own automated research system did most of the building, and because it targets local, offline use. Speed and benchmark numbers are vendor-reported, and the company itself says it needs more guidance than larger closed models.

### DuckDB 2.0.0 LTS "Cinnamon Teal" — the embedded analytics database gets its first 2.x long-term release
Released October 21 with support promised until at least October 2027. The headline additions are a first-class VARIANT type, triggers, asynchronous I/O and an agent mode. Worth noting before upgrading: it writes a new storage format that older versions can't open, so test on a copy first.

### Omnara — open-source durable agents backed by Postgres
Apache 2.0 control plane in Go that keeps agent state in your own Postgres and uses short-lived workers to advance it, so an agent can recover from crashes and disconnects. It surfaced as a Show HN this week as one of several self-hostable answers to Claude Managed Agents, and it's interesting because history stays queryable for evals and analytics. It doesn't migrate local files or running processes for you.
