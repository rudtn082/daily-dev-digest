# Daily Dev Digest — 2026-10-08

> Theme: Local-first and open-licensed — free creative suites, on-device search, a Git for agents, and a 150-language translator.

## Picks

### ArtCraft — seven free Adobe-style apps, built in Rust
A suite of seven creative apps from developer Brandon Thomas, each mirroring an Adobe program: PhotoCraft, LightCraft, FilmCraft, VectorCraft, PdfCraft, EffectCraft and DesignCraft. Most run on macOS, Windows and Linux, with browser versions for all but FilmCraft. Code is under MIT and Apache 2.0, and the apps are free to download; optional AI credit plans are the paid part. It drew heavy discussion on Hacker News this week.

### Cloudflare Artifacts — a versioned filesystem that speaks Git, built for agents
Open beta on the Workers Paid plan. Repos can be created and forked from code, wired to Workers for deploy-on-push, and subscribed to for events, with US or EU data jurisdiction per namespace. Cloudflare pitches it at the case where hundreds or thousands of agents work on one codebase at once, which classic Git workflows weren't designed for. Billing starts October 15, 2026.

### SCM (Screen Memories) — offline semantic search for your photos and videos on macOS
MIT-licensed Electron app with five search modes: by meaning, video scenes, on-screen text (OCR), spoken dialogue (Whisper) and local LLM chat with citations. Vision models are switchable (CLIP and SigLIP variants). The README states media never leaves the machine and there is no telemetry or account. It appeared on Show HN this week as a concrete example of fully local multimodal search.

### Index-Translate-35B-A3B-preview — Bilibili's open MoE translator for 150 languages
Apache 2.0 mixture-of-experts model, 35B total and 3B active parameters, built on a Qwen3.5 backbone. It ships with 2B and 9B siblings plus separate checkpoints for speech translation, dubbing and full-document translation. Reported scores include 0.8794 COMET-22 on FLORES and a 2.4% off-target rate on low-resource pairs (vendor-reported, still a preview). Only 3B active parameters makes a broad-coverage translator plausible on modest hardware.
