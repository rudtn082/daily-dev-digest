# Daily Dev Digest — 2026-11-28

> Theme: Agents on both sides of the wire

## Picks

### Cacti 4HTTP2ROOT — unpatched zero-day in the network monitoring tool
A researcher disclosed 4HTTP2ROOT on Nov 26: a stored SQL injection in Cacti 1.2.31 that alters the poller table and ends in OS command execution, reportedly in four HTTP requests when the guest account is enabled. As of Nov 28 the sources show no advisory, patched release or CVE from the Cacti project, and a security firm says it saw first attempts on its honeypots on Nov 27 (other reports say in-the-wild use is unconfirmed). Guest access is off by default, so check yours.

### Xalgorix — open-source AI pentester that re-exploits its own findings
An autonomous LLM agent runs a multi-phase web and repo pentest, then a separate verifier tries to re-exploit each candidate finding before it reaches the report. That "an agent's confident explanation is not a confirmed bug" rule is the interesting part, since false positives are the main complaint about AI scanners. Listings describe it as Apache-2.0 with paid hosted tiers; phase count differs by source (20 vs 22) and I found no independent accuracy benchmark.

### Cloudflare AI Search public endpoints — a search box for agents, per domain
Cloudflare AI Search instances can expose a public endpoint with `/mcp`, `/search` and `/chat/completions` paths, optionally on a custom domain behind Cloudflare Access. An aggregator dates the dashboard toggle ("Search for Agents") to Nov 25; the docs themselves show the feature predates that. Worth noting: if you gate a custom domain with Access, set `default_domain_enabled` to false or the default hostname keeps answering unauthenticated.
