# Daily Dev Digest — 2026-09-01

> Theme: The local turn — models and the agents that drive them both shrinking to fit hardware you already own.

## Picks

### Muse Glimmer — Meta's 30B open-weight model built for always-on local agents
Released by Meta Superintelligence Labs under Apache 2.0, aimed squarely at agent workloads that run on a laptop rather than a datacenter: multi-step planning, sequential tool calls, failure recovery, long-horizon tasks. The interesting part isn't the size but the target — most open weights are tuned to look good on chat and reasoning evals, and this one is tuned for the thing that actually breaks in production agents, which is the fifth tool call after something already went wrong.

### Ante — a coding agent that ships as one offline binary
A single Rust binary with no runtime dependencies, driving 12+ providers or local GGUF models with nothing phoning home. It has TUI, headless, server, and gateway modes, so the same binary is both your terminal agent and the thing your scripts call. The efficiency claims are the vendor's own and unreplicated, but the packaging argument stands on its own: an agent you can scp onto a box is a different tool from one that needs a Node install and an account.

### hax — a terminal agent written in C that respects your scrollback
Minimalist to the point of being a statement: a native C binary, a handful of dependencies, instant start, a few MB of memory. Local models are first-class — point it at llama-server and go. What sets it apart is the terminal manners: it redraws only the streaming line or the input area instead of seizing the alternate screen, so your scrollback survives the session. Small thing, and the reason people keep rewriting these tools.

### MIDI autocomplete — a 125M model that finishes your piano phrase on-device
One person trained a small model to predict the next few bars of piano and shipped it running locally in the browser. It's a good reminder of what the local turn looks like below the agent layer: at 125M parameters the latency budget is small enough that the model can sit inside an instrument's feedback loop rather than behind a request. Read it as a build log, not a product.
