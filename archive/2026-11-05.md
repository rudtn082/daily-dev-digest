# Daily Dev Digest — 2026-11-05

> Theme: Agents get hands and teammates — desktop apps, browser internals, and each other.

## Picks

### agent-desktop — Vercel Labs lets agents operate desktop apps through the accessibility tree
An Apache-2.0 project from Vercel Labs that gives AI agents a way to read and drive desktop applications via the OS accessibility tree rather than screenshots and pixel guessing. It is on the radar because computer use keeps moving from demos to libraries you can install. Its README warns that snapshots can contain private desktop content, so treat what an agent can see as a real permission boundary. I did not run it.

### Tucano — run a team of coding agents on your own machine
An Apache-2.0 tool that coordinates several agents locally. Agents talk in channels and hand work to each other, and it runs on top of Claude Code, Codex, Cursor CLI, OpenCode or Pi. It adds approval steps for risky actions such as merges or deletes. It is on the radar as another entry in the "orchestrate agents you already use" pile, with human gates built in rather than bolted on. Early project; verify before relying on it.

### Chrome DevTools for agents — CSS inspection and big-trace handling land in Chrome 155/156
Chrome's November DevTools notes add a `get_css_styles` tool so coding agents can read computed and matched styles (including inherited rules, pseudo-elements, keyframes and at-rules), a chunked parser for large performance traces with a 1.2 GB default buffer, automatic handling of JavaScript dialogs, and a config file for server flags. A "Get Chrome DevTools for agents" menu entry opens setup instructions. It matters because the browser vendor itself is now shipping agent-facing debugging surface, not a third-party shim.

### Tencent Hy4 — 770B MoE announced, weights still "in the coming days"
Tencent announced Hy4 on Nov 4: 770B total parameters with 49B active per token and a 1M+ token context, per secondary coverage. Weights and system cards are promised "in the coming days" with no date, and a preview repository exists. It is on the radar as another large Chinese open-weight entrant landing the same week as Mistral Large 4. The "leading open-source model" positioning is Tencent's own framing, with no independent benchmarks seen, and the license was not detailed.
