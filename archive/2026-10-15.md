# Daily Dev Digest — 2026-10-15

> Theme: Agents reach for old tools — disassemblers, MCP, and a frontier model whose weights are still pending.

## Picks

### REA (Reverse Engineer Anything) — an MCP bridge from coding agents to Ghidra, Hopper and IDA
Connects agents like Claude Code, Codex, Cursor and Gemini CLI to reverse-engineering tools over MCP, covering native binaries, Electron/JS apps, .NET assemblies, Android APKs, firmware and Go binaries. MIT licensed; setup is `npx rea-agents setup`, and native analysis needs your own Ghidra, Hopper or IDA install. It's on the radar because it treats the disassembler as the source of truth and lets the agent ask for more evidence. Caveats from the coverage: runtime capture executes the target with your user's permissions, and the DX-Ball reconstruction result is the developers' own claim. Authorized, lawful research only.

### Pi 1.0 — Earendil's minimal agent harness ships Codemode and flips on MCP
Pi, created by Mario Zechner and acquired by Earendil (Armin Ronacher, Colin Daymond Hanna) in April 2026, hit 1.0. New: Codemode (a harness-side sandbox for tool calls), deferred tool loading, Anthropic cache warming, and Pi Durable, a separate framework for long-running agent apps on SQLite/JSONL. The story is the reversal: Pi was known for arguing MCP was unnecessary, and now supports it, reasoning that both need a sandboxed interpreter.

### Beam — Reflection AI's 501B open-weight MoE, weights promised this month
Text-only mixture-of-experts, 501B total / 23B active parameters, 23.8T pretraining tokens, 1M-token context. Reflection says it matches leading Chinese open models on advanced reasoning at lower inference cost and will release weights and a technical report in October. Benchmark claims are the company's own and weights are not out yet, so this is a watch item, not something to download today. It matters because it's a US-lab attempt at an open frontier model.
