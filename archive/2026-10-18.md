# Daily Dev Digest — 2026-10-18

> Theme: Cheaper agent runs, models that remember, and a friendlier home for the harness.

## Picks

### DeepSeek V4.1-Flash-1017 — a cheaper, faster agentic checkpoint with open weights
DeepSeek shipped a new Flash checkpoint that, by its own numbers, scores 77.0% on DeepSWE at just under $0.20 per task, against 74.2% at around $0.50 for the previous one. It also adds Search and Fetch APIs, free through Oct 31 in DeepSeek Harness, Claude Code and Codex. All benchmark figures are DeepSeek's own; no independent results yet, and the license wasn't named in coverage.

### Kyutai REKI — a 2.4B robot-manipulation model that keeps memory
Reported as Kyutai's 2.4B vision-language-action model, trained only on public data, with weights on Hugging Face. The related NeurIPS 2026 paper's idea is memory tokens that carry past context through the action stream, so a robot doesn't act on the current frame alone. Rare open-weight entry in robotics; check the model card for license.

### Pi Agent Desktop — the Pi coding agent as a native app
A community MIT-licensed desktop wrapper for the Pi agent on macOS, Windows and Linux, built with Tauri and Next.js. It bundles Node and the Pi SDK, reads your existing `~/.pi/agent/` sessions and auth, and adds session browsing, conversation branching and git-worktree switching. It's on the radar because Pi 1.0 just shipped and this is the first GUI that doesn't ask CLI users to start over.
