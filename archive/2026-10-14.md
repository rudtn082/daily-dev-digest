# Daily Dev Digest — 2026-10-14

> Theme: Keeping agents honest — measuring code bloat, linting AI slop, packaging engineering habits as skills, plus two Rust builds.

## Picks

### Parsimony — an open-source benchmark for how much code AI models add
Instead of solve rate, it counts "coding units" (statements, calls, comparisons, names, literals) added minus removed in patches that existing benchmarks already published. Models are ranked by mean net units on solved tasks, lowest first; Python only, nothing re-executed. It's on the radar because it puts a number on a complaint everyone has: agents over-write. The author also notes that models writing more code tend to solve more tasks, and that size is not the same as quality.

### ai-deslop — Oxlint rules that reject low-signal AI-generated TypeScript
A plugin of opinionated Oxlint rules under the `deslop/*` namespace, covering type-safety shortcuts (chained type assertions, `unknown` parameters), a few code-quality patterns, and weak test patterns such as module mocking. Install with `npm install --save-dev ai-deslop`. Interesting because it moves "review the agent's output" from prose guidelines into a lint step that can fail CI. Some generic rules are vendored from dmmulroy/anti-slop.

### mattpocock/skills — Matt Pocock's `.agents` directory as an installable skill set
Around 27 skills for Claude Code, Codex, Copilot, Gemini CLI and others, e.g. `grill-with-docs`, `to-spec`, `to-tickets`, `implement`, `tdd`, `diagnosing-bugs`. MIT licensed. It showed up on GitHub's weekly trending list, which makes it a useful look at how a well-known TypeScript educator structures agent workflows: spec, tickets, TDD. Run `/setup-matt-pocock-skills` once per repo after installing.

### SolidCraft — open-source parametric CAD in pure Rust, with an MCP server
Sketch constraints, a feature timeline (extrude, revolve, sweep, loft, fillet), assemblies, sheet metal, STEP/IGES import and STEP/3MF/STL export. Runs as desktop app, in the browser, or headless CLI, and the MCP server lets agents model and measure parts. Dual MIT/Apache-2.0. The README calls it "early but usable for simple parts", so treat it as a project to watch rather than a SolidWorks replacement.

### mosh-rs — Mosh rewritten in Rust, with scrollback and a native Windows client
Wire-compatible with mosh 1.4.0, so you only need the client on your side. Adds opt-in scrollback into your local terminal history (needs a mosh-rs server) and a native Windows x86_64 client. Pre-alpha, GPL-3.0; the README lists no job control on Windows and no port or X forwarding. Worth a look because Windows and scrollback are the two things mosh users have long asked for.
