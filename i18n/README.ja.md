# Daily Dev Digest

開発とAI全般で、一度見ておく価値のある新しいツール・リポジトリ・アイデアを毎日短くまとめた一覧。
1日に数件、それぞれ「なぜ目に留まったか」を1行で。4言語で。

## これは何

毎日流れてくる量は追いきれない。これはそのフィルター — 1日3〜5件、それぞれなぜクリックする価値があるかを1行で。
テーマは固定しない。エージェント、インフラ、小さいが賢いツール、モデル、たまに風変わりな実験も。
その日の一覧はアーカイブにそのまま凍結 — 後からこっそり書き換えたりしない。

掲載したものとは無関係。ここにあるのは推薦ではなくポインタ — 自分で見て判断を。

知らずに広げていた信頼 — どのサイトの指示も聞いてしまった拡張機能の要素選択、安全なRustでも壊せる標準ライブラリ、誰でも再登録できる短縮リンク、エージェント用サンドボックスのDBブランチ。

| ピック | 何か | 気になった理由 |
|------|-----------|-----------|
| **uBlock Origin(Firefox)のユニバーサルXSS** | 悪意あるサイトが拡張の要素ピッカーを悪用し、任意のドメインでJavaScriptを実行できた | 記事によればクリック1回で成立。修正済みとされるがバージョンは不明。拡張は最新に |
| **Hyenas(Microsoft FORGE Lab)** | Rustのcore/std標準ライブラリの健全性バグを見つけたAIスキャナ | 安全なコードから未定義動作を起こせた。修正の1件はRust 1.100に入るとされ、他は未確認 |
| **Bitlyの失効リンク** | 昔のBurger King・McDonald's・Trumpのツイートの失効した短縮リンクを第三者が再登録 | 報道ではハッキングではなく末尾が再び空いただけ。公開した短縮リンクは自分で制御できない依存先 |
| **db-branch** | ZFSクローンで作る即時のMySQL/PostgreSQLブランチ、CLI・REST・MCPサーバ付き | エージェントのサンドボックスやPR単位のCI向けの軽い使い捨てDB。Apache-2.0、ZFSが必要とみられる |

## 選び方

- 1日3〜5件、多くて5件。目立つものがない日は少なめに。
- 重複なし — アーカイブにあるものと照合。
- 皆が知る巨大プロジェクトより、伸びているものを優先。
- 有料枠・アフィリエイトリンクなし、例外なし。

提案したい、または自分で複製して回したいなら [`CONTRIBUTING.md`](../CONTRIBUTING.md)。
