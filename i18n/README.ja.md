# Daily Dev Digest

開発とAI全般で、一度見ておく価値のある新しいツール・リポジトリ・アイデアを毎日短くまとめた一覧。
1日に数件、それぞれ「なぜ目に留まったか」を1行で。4言語で。

## これは何

毎日流れてくる量は追いきれない。これはそのフィルター — 1日3〜5件、それぞれなぜクリックする価値があるかを1行で。
テーマは固定しない。エージェント、インフラ、小さいが賢いツール、モデル、たまに風変わりな実験も。
その日の一覧はアーカイブにそのまま凍結 — 後からこっそり書き換えたりしない。

掲載したものとは無関係。ここにあるのは推薦ではなくポインタ — 自分で見て判断を。

## 今日 — 2026-09-16

トークン1つ、レビュー1回、GPU 1時間の値段 — AIのコストを自分で確かめられる数字にする3つのプロジェクト。

| ピック | 何か | なぜ目に留まったか |
|------|-----------|--------------------|
| **Colibri** | エキスパートをディスクからストリーミングし、手持ちのハードでフロンティアMoEを動かす | 純粋なC、依存ゼロで、VRAM・RAM・ディスクを1つの階層として扱う。OLMoEからKimi K3まで9系統が動き、transformersとトークン単位で一致を検証 — READMEは「速度はディスクで決まる」と率直に書いている(5090×6で約6 tok/s、128GBのCPUデスクトップで約1.8)。問いが「載るか」から「自分のSSDはトークンにしていくらか」に変わる。Apache 2.0 |
| **Open Code Review** | Alibaba社内のコードレビュアーをCLIとして公開 | ファイル選択、関連ファイルのまとめ、ルール照合、コメント位置はハードコードし、LLMエージェントは判断とコンテキスト取得だけを担う — 汎用エージェント比でトークン約1/9、精度も上がったと報告(自社の数字なので自分のリポジトリで測ること)。モデルが要らない工程はすべてモデルから取り上げる、という設計。GitHub Actions、GitLab CI、Claude Code・Codex・Cursorのプラグイン対応。Apache 2.0 |

## 選び方

- 1日3〜5件、多くて5件。目立つものがない日は少なめに。
- 重複なし — アーカイブにあるものと照合。
- 皆が知る巨大プロジェクトより、伸びているものを優先。
- 有料枠・アフィリエイトリンクなし、例外なし。

提案したい、または自分で複製して回したいなら [`CONTRIBUTING.md`](../CONTRIBUTING.md)。
