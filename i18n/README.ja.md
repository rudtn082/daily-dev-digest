# Daily Dev Digest

開発とAI全般で、一度見ておく価値のある新しいツール・リポジトリ・アイデアを毎日短くまとめた一覧。
1日に数件、それぞれ「なぜ目に留まったか」を1行で。4言語で。

## これは何

毎日流れてくる量は追いきれない。これはそのフィルター — 1日3〜5件、それぞれなぜクリックする価値があるかを1行で。
テーマは固定しない。エージェント、インフラ、小さいが賢いツール、モデル、たまに風変わりな実験も。
その日の一覧はアーカイブにそのまま凍結 — 後からこっそり書き換えたりしない。

掲載したものとは無関係。ここにあるのは推薦ではなくポインタ — 自分で見て判断を。

エージェントがターミナルを出る:アプリを直接操作し、CLI 特化モデルとして登場し、Brotli のバグと Reddit の禁止令にぶつかった。

| ピック | 何か | 気になった理由 |
|------|-----------|-----------|
| **Cursor Computer Use** | Cursor のエージェントがデスクトップアプリや iOS シミュレータをクリック・入力で操作 | 「コンパイルできる」から「アプリが動く」までを、ネイティブ/モバイルアプリでも閉じられる。macOS のアクセシビリティと画面収録の許可が必要 |
| **IQuest-Q1** | コマンドライン向けエージェント用の 320B スパース MoE(アクティブ 15B、コンテキスト 512K) | 著者はウェイト公開と、後継モデルの開発にモデル自身が関わったと主張。スコアは自己申告で、ライセンスは未確認 |
| **Node2Shell (CVE-2026-111497)** | Node.js・Bun・Envoy に及ぶ Brotli デコーダの境界外書き込み | Node は 10 月 21 日に修正(22.23.4 / 24.22.1 / 26.12.1)、PoC あり。Brotli を同梱するアプリは個別に更新が必要 |

## 選び方

- 1日3〜5件、多くて5件。目立つものがない日は少なめに。
- 重複なし — アーカイブにあるものと照合。
- 皆が知る巨大プロジェクトより、伸びているものを優先。
- 有料枠・アフィリエイトリンクなし、例外なし。

提案したい、または自分で複製して回したいなら [`CONTRIBUTING.md`](../CONTRIBUTING.md)。
