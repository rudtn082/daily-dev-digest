# Daily Dev Digest

開発とAI全般で、一度見ておく価値のある新しいツール・リポジトリ・アイデアを毎日短くまとめた一覧。
1日に数件、それぞれ「なぜ目に留まったか」を1行で。4言語で。

## これは何

毎日流れてくる量は追いきれない。これはそのフィルター — 1日3〜5件、それぞれなぜクリックする価値があるかを1行で。
テーマは固定しない。エージェント、インフラ、小さいが賢いツール、モデル、たまに風変わりな実験も。
その日の一覧はアーカイブにそのまま凍結 — 後からこっそり書き換えたりしない。

掲載したものとは無関係。ここにあるのは推薦ではなくポインタ — 自分で見て判断を。

## 今日 — 2026-09-14

コーディングエージェントの分解 — ウェイト、サービング、ハーネスがそれぞれ差し替え可能な部品になりつつある。

| ピック | 何か | なぜ目に留まったか |
|------|-----------|--------------------|
| **OpenSAS** | エージェントが書いたオープンソースの SAS 9.4 インタープリタ | Zig 製で、7 つのコーディングエージェントが公開ドキュメントだけを頼りに構築し、臨床パイプライン(SDTM、ADaM)でプロプライエタリ版とバイト単位で同じ出力を出すと主張している — 規制下の治験データは「だいたい合っている」が即失敗になる領域で、また一つの todo アプリよりずっと鋭くエージェント製ソフトウェアを試す。一致の主張はプロジェクト自身のものなので、自分のパイプラインで確かめたい |
| **GLM-5.3-Flash** | Z.ai 初のネイティブマルチモーダル GLM-5、MIT ライセンス | 320B の MoE(アクティブ 18B)、1M コンテキスト、テキスト・画像・動画・ファイル入力、fp8 ウェイトを Hugging Face で公開 — Z.ai が名乗り出るまで OpenRouter 上で「Ox Alpha」という匿名モデルとして動いていた。売上条件も用途制限もないライセンスこそが製品に載せられる理由で、ベンチマークの図より効いてくる |
| **Magnitude** | 普段使いのエージェントにそのまま挿さるローカル推論サーバー | チップ・メモリ・帯域をプロファイルしてモデルごとの適合度と tok/s を見積もり、選んだモデルをダウンロード・調整して Pi、OpenCode、Hermes、Codex、Claude Code、Cline 向けに配信する — ローカル派が本当に詰まる所に答えている。「モデルを動かせるか」ではなく「このマシンでエージェントループに耐えるのはどれか」だ |
| **Pi** | 分解して使えるエージェントツールキット | マルチプロバイダ統合 LLM API、エージェントランタイム、TUI コンポーネント、コーディングエージェント CLI を別々のパッケージとして提供し、Node に組み込むことも RPC で動かすこともできる — トレンドで Magnitude のすぐ隣に並んでいて、その組み合わせこそが要点だ。ハーネスが製品ではなくライブラリになり、ループもモデルも UI も一社の決定ではなくなる |

## 選び方

- 1日3〜5件、多くて5件。目立つものがない日は少なめに。
- 重複なし — アーカイブにあるものと照合。
- 皆が知る巨大プロジェクトより、伸びているものを優先。
- 有料枠・アフィリエイトリンクなし、例外なし。

提案したい、または自分で複製して回したいなら [`CONTRIBUTING.md`](../CONTRIBUTING.md)。
