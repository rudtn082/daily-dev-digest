## 오늘 — 2026-11-15

가장자리의 신뢰 — 검증 못 하는 릴리스를 알려주는 패키지 저장소, 앱이 데이터를 흘린 앱 빌더, 그리고 로컬 AI가 얹힌 배관(ggml, 에이전트용 브라우저).

| 픽 | 뭔데 | 왜 눈에 띄었나 |
|------|-----------|-----------|
| **PyPI 출처 경고** | 출처를 검증할 수 없는 릴리스에 PyPI가 경고 표시 | 보안 탭과 출처 누락·불완전·변경 경고 추가. 악성 패키지 자체는 못 잡고, 오래된 릴리스 다수는 증명이 없음 |
| **Lovable 앱 유출** | 연구진이 Lovable 프로젝트 159,041개를 스캔, 로그인 없이 데이터가 노출된 Supabase 앱 발견 | 비공개 메시지 20만 건과 여권번호 포함. Lovable 설명은 RLS 부족. RLS를 점검할 것. 연구진 주장 기준 |
| **ggml 1.0.0** | llama.cpp류 로컬 추론의 기반 텐서 라이브러리가 1.0 도달 | 레거시 API 제거(하위 코드가 깨질 수 있음), FP8 지원과 다양한 백엔드 최적화 |
| **Agweb** | 코딩 에이전트용 macOS WebKit 브라우저, `agweb` 셸 명령으로 제어 | 포커스를 뺏지 않고 무거운 헤드리스 브라우저를 피함. 확인한 페이지엔 라이선스 표기 없음 |
