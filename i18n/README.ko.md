## 오늘 — 2026-09-01

로컬로의 회귀 — 모델도, 그 모델을 굴리는 에이전트도 이미 네가 가진 하드웨어에 맞게 작아지고 있다.

| 픽 | 뭔데 | 왜 눈에 띔 |
|------|-----------|------------|
| **Muse Glimmer** | 상시 구동 로컬 에이전트를 겨냥한 메타의 30B 오픈 웨이트 모델 | Meta Superintelligence Labs가 Apache 2.0으로 냈고, 데이터센터가 아니라 노트북에서 도는 에이전트 작업을 정조준한다 — 다단계 계획, 순차 툴 호출, 실패 복구. 크기가 아니라 표적이 핵심인데, 대부분의 오픈 웨이트가 챗·추론 벤치에서 예뻐 보이게 튜닝될 때 이건 실전에서 실제로 터지는 지점, 즉 이미 뭔가 잘못된 뒤의 다섯 번째 툴 호출을 노린다 |
| **Ante** | 오프라인 단일 바이너리로 배포되는 코딩 에이전트 | 런타임 의존성 없는 Rust 바이너리 하나가 12개 이상 공급자 또는 로컬 GGUF 모델을 굴리고 아무 데도 신호를 보내지 않는다. TUI·헤드리스·서버·게이트웨이 모드까지 — 효율 수치는 제작사 자체 주장이고 재현된 바 없지만, 패키징 논지는 그것만으로 선다. scp로 서버에 던져 넣을 수 있는 에이전트는 Node 설치와 계정을 요구하는 물건과 아예 다른 도구다 |
| **hax** | C로 쓴, 네 스크롤백을 건드리지 않는 터미널 에이전트 | 네이티브 C 바이너리, 의존성 몇 개, 즉시 시작, llama-server로 로컬 모델을 일급으로 취급 — 차별점은 터미널 예의다. 대체 화면을 통째로 뺏는 대신 스트리밍 중인 줄과 입력 영역만 다시 그려서 세션이 끝나도 스크롤백이 남는다. 사소한 얘기 같지만, 사람들이 이 도구를 계속 다시 만드는 이유가 딱 이런 것들이다 |
| **MIDI autocomplete** | 피아노 프레이즈를 이어서 쳐주는 125M 온디바이스 모델 | 한 사람이 다음 몇 마디를 예측하는 작은 모델을 학습시켜 브라우저에서 로컬로 돌게 만들었다 — 에이전트 계층 아래에서 로컬 회귀가 어떤 모습인지 보여주는 사례로, 125M 정도면 지연 예산이 충분히 작아 모델이 요청 뒤편이 아니라 악기의 피드백 루프 안에 앉을 수 있다. 제품이 아니라 빌드 로그로 읽을 것 |
