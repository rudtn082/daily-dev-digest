## 오늘 — 2026-07-28

에이전트가 이제 네 환경에 들르는 게 아니라 아예 눌러앉기 시작했다 — 로그인된 브라우저 세션, 팀 채팅방, 문서, 그리고 네 하드웨어 안까지.

| 픽 | 뭔데 | 왜 눈에 띔 |
|------|-----------|------------|
| **ego-lite** | 로그인된 세션을 코딩 에이전트에게 그대로 넘겨주는 브라우저 | 대부분의 에이전트 자동화는 빈 프로필에서 시작해 첫 로그인 벽에서 죽는다; ego-lite는 실행 시 크롬 데이터를 옮길지 물어봐서 에이전트가 쿠키와 확장을 그대로 물려받되 네 탭은 건드리지 않고 자기 Space에서 일한다 — 이번 주 깃허브 트렌딩 1위, 근거는 Vercel agent-browser 대비 네 개 작업에서 더 빠르고 토큰도 덜 썼다는 벤치 |
| **Buzz** | 에이전트가 정식 구성원인, Block의 셀프호스팅 워크스페이스 | 채팅·git 호스팅·에이전트를 한 화면에 묶은 Apache-2.0 프로젝트, 밑바닥은 러스트로 짠 Nostr 릴레이; 핵심은 "슬랙+깃허브" 문구가 아니라 에이전트가 자기 암호 키와 채널 멤버십을 가진다는 점 — 패치나 리뷰 승인이 익명 봇 행위가 아니라 감사 로그에 서명된 이벤트로 남는다 |
| **Kimi K3** | 지금까지 풀린 오픈 웨이트 중 최대: 2.8T 파라미터 | Moonshot이 7월 27일 00:00 UTC에 게이트 없이 허깅페이스에 올렸다 — 샤드 96개, MXFP4로 약 1.56TB; 다만 올리기 전에 읽어야 할 건 `license:other`로 태깅된 별도의 "Kimi K3 License"다. 매출 기준을 넘으면 별도 계약을 요구하고 UI 표기 의무까지 붙는다. 공개 시점 기준 독립 벤치마크는 없음 |
| **OpenWiki** | 사람이 아니라 에이전트가 읽을 문서를 써주는 LangChain CLI | LLM 컨텍스트 창에 맞춘 `openwiki/` 폴더를 생성하고, 글보다 그림이 나은 자리엔 Mermaid 다이어그램을 넣는다; 흔한 README 생성기와 갈리는 지점은 같이 들어있는 깃허브 액션 — 매일 PR을 열어줘서 문서가 낡는 문제를 의지력이 아니라 머지 큐 항목으로 바꿔놓는다 |
