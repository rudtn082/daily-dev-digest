## 오늘 — 2026-11-16

모르고 넓혀 둔 신뢰 — 아무 사이트의 명령을 받던 차단기의 요소 선택기, 안전한 Rust가 깨뜨릴 수 있는 표준 라이브러리 코드, 누구나 다시 등록할 수 있는 단축 링크, 에이전트 샌드박스용 DB 브랜치.

| 픽 | 뭔데 | 왜 눈에 띄었나 |
|------|-----------|-----------|
| **uBlock Origin(Firefox) 범용 XSS** | 악성 사이트가 확장 프로그램의 요소 선택기를 악용해 어떤 도메인에서든 JavaScript 실행 가능 | 글에 따르면 클릭 한 번이면 충분. 패치됐다고 하나 버전은 명시 안 됨. 확장 프로그램을 최신으로 유지할 것 |
| **Hyenas(Microsoft FORGE Lab)** | Rust core·std 라이브러리의 건전성(soundness) 버그를 찾아낸 AI 기반 스캐너 | 안전한 코드로도 미정의 동작을 일으킬 수 있었음. 수정 하나는 Rust 1.100에 반영 예정으로 알려졌고 나머지는 미확인 |
| **Bitly 만료 링크** | 예전 Burger King·McDonald's·Trump 트윗의 만료된 단축 링크를 타인이 다시 등록 | 보도에 따르면 해킹이 아니라 주소가 다시 풀린 것. 내가 뿌린 단축 링크는 내가 통제하지 못하는 의존성 |
| **db-branch** | ZFS 클론으로 만드는 즉석 MySQL/PostgreSQL 브랜치, CLI·REST·MCP 서버 제공 | 에이전트 샌드박스와 PR별 CI용 가벼운 일회용 DB. Apache-2.0, ZFS가 필요한 것으로 보임 |
