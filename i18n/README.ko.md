## 오늘 — 2026-10-22

에이전트에 울타리를: 권한 스펙, 쉬지 않고 빌드하는 플러그인, 그리고 모델을 막으려고 만든 언어.

| 픽 | 뭔데 | 왜 눈에 띄었나 |
|------|-----------|-----------|
| **Docker Sandbox Kit Spec v3** | 에이전트의 접근 권한(네트워크, 자격 증명, 볼륨)을 컨테이너 이미지 안에 선언하는 Apache 2.0 오픈 스펙 | 권한을 서명하고 리뷰할 수 있게 됨. 새 버전이 더 많은 접근을 요구하면 다시 승인받아야 함. Docker는 CNCF 제출을 계획 중 |
| **Superlite** | 계획 하나만 승인하면 멈추지 않고 병렬로 빌드하는 Claude Code 플러그인 | Superpowers의 정반대 접근: 여러 번 대신 승인 한 번. 16.1분 대 33.6분 벤치마크는 작성자가 한 번 돌린 결과 |
| **KillSwitch** | LLM이 풀기 어렵게 설계한 난해한 스택 언어. 스펙에 거짓이 숨어 있고 글자 수 규칙이 있음 | 낯선 스펙에서 모델이 어떻게 무너지는지 보는 장난스러운 실험. 작성자 자체 최고 점수는 단순한 과제에서 66.8 |
| **Timestral** | Mistral의 첫 시계열 파운데이션 모델. 5M~209M 파라미터, CPU 추론 가능 | Mistral이 언어 모델 밖으로 나와 작은 예측 모델을 냄. 수정 MIT 라이선스 |
