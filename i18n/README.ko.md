## 오늘 — 2026-09-16

토큰 하나, 리뷰 한 번, GPU 한 시간의 값 — AI 비용을 직접 확인할 수 있는 숫자로 만드는 세 프로젝트.

| 픽 | 뭔데 | 왜 눈에 띔 |
|------|-----------|------------|
| **Colibri** | 디스크에서 전문가를 스트리밍해 이미 가진 하드웨어로 프런티어 MoE 돌리기 | 순수 C, 의존성 제로, VRAM·RAM·디스크를 하나의 계층으로 다룬다. OLMoE부터 Kimi K3까지 9개 계열을 돌리고 transformers와 토큰 단위로 일치를 검증한다 — README가 대놓고 "속도는 디스크가 정한다"고 적어두었다(5090 여섯 장에서 ~6 tok/s, 128GB CPU 데스크톱에서 ~1.8). 질문이 "올릴 수 있나"에서 "내 SSD가 토큰으로 얼마짜리인가"로 바뀐다. Apache 2.0 |
| **Open Code Review** | 알리바바 사내 코드 리뷰어를 CLI로 공개 | 파일 선택, 관련 파일 묶기, 규칙 매칭, 코멘트 위치 지정은 하드코딩하고 LLM 에이전트는 판단과 컨텍스트 조회만 맡는다 — 범용 에이전트 대비 토큰 약 1/9에 정밀도는 더 높다고 보고한다(자체 수치이니 네 저장소에서 재볼 것). 모델이 필요 없는 단계는 전부 모델에게서 뺏는다는 설계. GitHub Actions, GitLab CI, Claude Code·Codex·Cursor 플러그인. Apache 2.0 |
| **Computable GPU Index** | H100·H200·B200·B300 한 시간의 가격을 공개·재현 가능하게 산출하는 지수 | 고정 공급자 패널의 가중 투표에서 가운데 구간만 평균해 꼬리 쪽 몇 곳이 값을 끌고 가지 못하게 하고, 저장소를 클론하면 공개된 어떤 값이든 다시 계산할 수 있다. 키 없는 익명 API — GPU 가격은 대개 GPU 파는 쪽이 부르는 값이라, 직접 재계산 가능한 숫자는 예산과 계약에 쓸모가 있다. 코드 Apache 2.0, 데이터 CC BY-NC |
