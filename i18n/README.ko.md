## 오늘 — 2026-07-27

오늘 픽 중에 새 아이디어는 하나도 없다. 전부 오래된 아이디어를 드디어 쓸 만하게 만든 마지막 조각이다 — 캐시, 라이선스, 전처리, compose 파일, 라이프사이클.

| 픽 | 뭔데 | 왜 눈에 띔 |
|------|-----------|------------|
| **oMLX** | 같은 컨텍스트를 다시 계산하지 않게 해주는 MLX 추론 서버 | 에이전트는 매 턴 프롬프트 앞부분이 바뀌는데 다른 MLX 서버는 그때마다 KV 캐시를 버려서 응답당 30~90초가 날아간다; oMLX는 KV 블록을 SSD에 페이지 단위로 저장했다 복원해 첫 토큰까지 몇 초로 줄인다 — 애플 실리콘에서 로컬 에이전트가 쓸 만해지려면 반드시 있어야 했던 것 |
| **Inkling** | Thinking Machines Lab의 첫 모델: 975B MoE, 오픈 웨이트, Apache 2.0 | 토큰당 활성 41B, 1M 컨텍스트, 텍스트·이미지·오디오 네이티브 추론, 45T 토큰 프리트레이닝 — 하지만 진짜 얘깃거리는 미국 랩이 이 규모 모델에 붙인 라이선스, 그리고 호출할 엔드포인트가 아니라 파인튜닝할 베이스로 내놨다는 점 |
| **Infini-News** | 커먼 크롤 뉴스 기사 13.6억 건을 밀리초 단위로 질의 | 뉴스 연구는 비싼 상용 아카이브나 테라바이트짜리 원본 CC-News에 막혀 있었다; 이건 추출·정제·언어 태깅·국가 귀속(기사 83.4%, 222개국)을 한 번에 끝내고 infini-gram 인덱스까지 얹어 전체 아카이브를 1초 안에 패턴 검색하게 해줌 |
| **Fruitbox** | 애플 컨테이너 런타임용 Docker Compose | 애플 `container`가 1.0을 찍었지만 아무도 컨테이너 하나만 띄우지 않는다 — 서비스 다섯 개짜리 compose 파일을 띄운다; 흥미로운 건 네이티브 런타임 주변에 생태계가 붙기 시작했다는 신호, 그게 맥에서 진짜 도커 대안이 되는 조건 |
| **Frond** | 앱의 의존성 그래프를 다루는 프론트엔드 런타임 | 라우터도 렌더러도 아니다 — 그 아래층으로, 각 노드가 어떻게 획득·취소·해제되는지 한곳에 선언해 React는 이미 준비된 걸 소비만 한다; Effect 위에 올려서 노드가 제거되면 fetch가 실제로 중단되고 타이머가 정리되고 스트림이 닫힘 |
