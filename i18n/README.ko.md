## 오늘 — 2026-09-15

에이전트가 도는 머신에 계기판이 붙는다 — 뭐가 깔렸는지 보고, 세션을 살려두고, 잘못된 쓰기를 되돌린다.

| 픽 | 뭔데 | 왜 눈에 띔 |
|------|-----------|------------|
| **DeepSeek-V4.1-Flash** | 읽을 땐 8B, 쓸 땐 16B만 켜는 552B MoE, MIT 라이선스 | Causal Encoder-Decoder 구조라 프리필은 토큰당 8B, 디코드는 16B만 활성화한다. 1M 컨텍스트, 이미지·텍스트 입력, API에서 V4 Flash를 대체한 당일 Hugging Face에 웨이트 공개 — 진짜 봐야 할 숫자는 모델 카드의 토큰당 KV 캐시 약 890바이트(V4 Flash의 4분의 1 수준)다. 긴 에이전트 루프는 벤치 점수보다 캐시 메모리에서 먼저 막힌다 |
| **Hydra** | 창을 닫아도 세션이 살아 있는 에이전트 터미널 | 데스크톱 앱은 로컬 PTY 데몬의 클라이언트일 뿐이라 앱을 닫아도 셸과 에이전트가 계속 돌고, 인바운드 포트 없이 브라우저로 붙을 수 있다. 이미 떠 있는 Claude Code·Codex·Copilot CLI·OpenCode·Cursor Agent 세션을 찾아 이어 붙인다 — 오래 남는 단위가 탭이 아니라 에이전트 세션이라는 발상. 로컬 코드는 MIT, Remote 서비스는 별도 비공개 |
| **Geiger** | 내 머신의 에이전트 전부와, 각자 뭘 건드릴 수 있는지 | 읽기 전용 `npx geiger-scan` 하나로 Claude Code 설정, MCP 호스트 설정, IDE·브라우저 확장, 전역 npm 패키지를 훑어 EXECUTES·HOLDS-SECRETS·BROAD-FILESYSTEM 등으로 태깅하고, 기준선 대비 변화도 잡는다 — 런타임이 아니라 설정만 보니 무슨 일이 있었는지가 아니라 터지면 어디까지인지를 알려주지만, 그것만 해도 대부분의 개발 머신은 지금 답을 못 한다 |
| **EterDB** | DB 전체 복구 없이 잘못된 트랜잭션 하나만 되돌리기 | Postgres 18 기반, append-only 이력을 남겨 특정 트랜잭션이 건드린 행만 되돌리고, 드롭된 테이블을 값째 복구하고, 오염된 데이터를 읽은 후속 쓰기까지 추적하고, 과거 시점 조회도 된다 — PITR은 실수 이후의 정상 쓰기까지 다 날리는데, 그런 실수가 점점 연결 문자열 쥔 에이전트에게서 나온다. Apache 2.0 |
