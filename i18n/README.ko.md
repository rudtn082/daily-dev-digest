| 픽 | 뭔데 | 왜 눈에 띄었나 |
|------|-----------|-----------|
| **TorchNeuron** | AWS Trainium2/3용 Amazon의 Apache 2.0 PyTorch 백엔드, 퍼블릭 베타 | 설정 한 줄로 기존 PyTorch 코드를 실행, Nvidia의 소프트웨어 종속을 겨냥. 초기 버전이라 동적 shape 미지원, 많은 PyTorch 테스트 건너뜀 |
| **MiniMax M3.1 Flash** | 100만 토큰 컨텍스트와 조절 가능한 추론 깊이를 갖춘 멀티모달 에이전트 모델. 오픈 웨이트는 10월 23일 공개 예고 | 저렴한 API 가격과 회사 발표 기준 큰 속도 향상. 발표 시점엔 크기와 라이선스 미공개라 Hugging Face부터 확인할 것 |
