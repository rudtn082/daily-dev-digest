## 오늘 — 2026-08-03

이제 상품은 에이전트가 아니라 그 주변 배관이다 — 뭘 볼 수 있고, 뭘 만질 수 있고, 뭘 읽을 수 있고, 누가 감독하느냐.

| 픽 | 뭔데 | 왜 눈에 띔 |
|------|-----------|------------|
| **Screenpipe** | 에이전트가 질의할 수 있는, 로컬에 쌓이는 24/7 작업 기록 | 7월의 방향 전환이 전부다 — 화면 녹화를 파는 게 아니라 "네가 일하는 걸 녹화해서 검색 가능한 기억, 나아가 에이전트가 실행할 SOP로 바꿔준다"를 판다; 화면과 소리는 로컬 SQLite에 들어가고 MCP로 다시 나오니, 반복 작업을 지켜본 에이전트가 매번 프롬프트로 끌려다니는 대신 절차를 스스로 적어둔다 |
| **Coasty** | 컴퓨터 조작 에이전트용 API, 런타임은 오픈소스로 공개 | 작업을 던지고 머신이나 브라우저를 고르고 자격증명을 넘기면 에이전트가 스크린샷·마우스·키보드로 조작한 뒤 결과를 검증한다 — 그런데 볼 이유는 `open-computer-use` 쪽이다. 호스팅 블랙박스에 묶이는 대신 API 키 하나로 같은 루프를 직접 돌릴 수 있다 |
| **Context.dev** | 에이전트에게 먹일 깨끗한 웹 컨텍스트를, 심심한 API 하나로 | URL을 LLM용 마크다운으로 긁고, 네 JSON 스키마로 추출하고, 사이트맵 따라 전체를 크롤한다 — JS 렌더링·안티봇 대응·스텔스 프록시가 크레딧 추가 없이 모든 요청에 포함되는데, 다들 이 층을 다시 만들면서 결국 프록시 요금으로 값을 치른다 |
| **OpenHands Agent Canvas** | 이미 쓰는 에이전트가 뭐든, 그걸 감독하는 셀프호스팅 관제실 | 경쟁이 아니라 감독이다: OpenHands 자체 에이전트, Claude Code, Codex, Gemini 등 Agent Client Protocol을 말하는 건 전부 한 캔버스에 올린다 — ACP를 이음매로 잡았다는 건 다음 싸움터가 에이전트가 아니라 오케스트레이션 표면이라는 뜻 |
