## 오늘 — 2026-11-18

에이전트의 청구서와 숙제 — 코딩 에이전트 비용을 깎고, 건네주는 스킬을 채점하고, 데몬으로 돌리는 도구들, 그리고 조용히 15배 비싸진 기본 모델 교체.

| 픽 | 뭔데 | 왜 눈에 띄었나 |
|------|-----------|-----------|
| **TokenEconomizer** | 저장소 사실을 학습하고 안 쓰는 도구를 걷어내며 막힌 턴을 찔러 주어 코딩 에이전트를 더 싸게 돌리는 Microsoft의 MIT 라이선스 플러그인 | 이번 주 불만은 성능이 아니라 비용. Claude Code, Codex, Copilot CLI 지원. 절감 효과는 직접 측정 못 함 |
| **SkillEvaluator** | 에이전트 스킬을 검증하고 중복을 확인하며, 샌드박스에서 스킬 유무를 비교해 주는 NVIDIA 도구 | 스킬이 검증 없이 패키지처럼 설치되는 현실에서 나온 테스트 스위트. 실험적 |
| **agentproto** | 코딩 에이전트 세션을 백그라운드로 돌리고 CLI·HTTP·MCP로 도구를 노출하는 오픈 TypeScript 데몬 | 계정 간 사용량 한도 페일오버, 오래된 CI 이벤트 필터링 등 장시간 에이전트의 지루하지만 중요한 문제를 다룸. 릴리스 노트만 확인, 직접 써 보진 않음 |
| **Browser Use 1.0.6** | `Agent(task)`의 기본 모델을 `bu-4.0`으로 바꾼 릴리스 | `bu-fast`의 15배 가격으로 표기. 업그레이드 전에 모델을 명시해 두자 |
