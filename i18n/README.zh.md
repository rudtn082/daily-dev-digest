## 这是什么

每天上新的东西太多，跟不完。这就是我的过滤器 —— 每天 3~5 条，各用一行说明为何值得一点。

与所列项目无关。这里的条目是指路，不是推荐 —— 自己去看，自己判断。

## 今天 — 2026-08-03

如今的产品已经不是智能体本身，而是它周边的管道 —— 它能看到什么、能操作什么、能读到什么，以及谁来监管它。

| 精选 | 是什么 | 为何引起注意 |
|------|-----------|--------------|
| **Screenpipe** | 一份留在本地、供智能体查询的 24/7 工作台账 | 七月的重新定位就是全部卖点 —— 不再卖录屏，而是卖"把你的工作方式录下来，变成可检索的记忆，再变成智能体能执行的 SOP"；画面与音频进本地 SQLite，再经 MCP 出来，于是看过你重复操作的智能体会把步骤写下来，而不是每次都要你手把手提示 |
| **Coasty** | 面向电脑操作智能体的 API，运行时已开源 | 你用自然语言下达任务、选机器或浏览器环境、交出凭据和文件，智能体便通过截图、鼠标与键盘操作界面，核验结果后返回 —— 但真正值得看的是 `open-computer-use`，一把 API key 就能自己跑同一套循环，不必绑死在托管黑盒上 |
| **Context.dev** | 把喂给智能体的干净网页上下文，收进一个乏味的 API | 把 URL 抓成适合 LLM 的 markdown、按你的 JSON schema 抽取、沿 sitemap 爬完整站 —— JS 渲染、反爬对抗与隐身代理都包含在每次请求里且不额外计费，而这一层人人都在重造，代价最后多半付在代理账单上 |
| **OpenHands Agent Canvas** | 不管你已经在用哪个智能体，都由它来监管的自托管控制室 | 它不是竞争而是监管：OpenHands 自家的智能体、Claude Code、Codex、Gemini，凡是会说 Agent Client Protocol 的都能放上同一块画布 —— 把 ACP 选作接缝，意味着下一场争夺在编排层面，而不在智能体本身 |

## 怎么挑的

- 没有付费位、没有联盟链接，没有例外。
