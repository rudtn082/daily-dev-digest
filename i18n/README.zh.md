## 今天 — 2026-07-27

今天没有一个是新点子。每一项都是让一个旧点子终于变得可用的那块缺失拼图 —— 缓存、许可证、预处理、compose 文件、生命周期。

| 精选 | 是什么 | 为何引起注意 |
|------|-----------|--------------|
| **oMLX** | 让你的 Mac 不再重算同一段上下文的 MLX 推理服务器 | 智能体每一轮的提示前缀都在变，而其他 MLX 服务器每次都丢弃 KV 缓存，一次回复就要等 30～90 秒；oMLX 把 KV 块分页落到 SSD 再恢复，首字延迟压到几秒 —— 这是 Apple Silicon 上本地智能体能用起来的前提 |
| **Inkling** | Thinking Machines Lab 的首个模型：975B MoE、开放权重、Apache 2.0 | 每 token 激活 41B、1M 上下文、原生文本/图像/音频推理、45T token 预训练 —— 但真正的看点是一家美国实验室给这个体量的模型挂上了这张许可证，而且是当作可微调的基座发布，而不是一个供调用的端点 |
| **Infini-News** | 13.6 亿篇 Common Crawl 新闻，毫秒级可查 | 新闻研究一直卡在昂贵的商业档案和数 TB 的原始 CC-News 之间；这个项目把抽取、清洗、语言标注和国别归属（83.4% 的文章、222 个国家）一次做完，还配上 infini-gram 索引，让整个档案的模式检索在一秒内完成 |
| **Fruitbox** | 面向苹果容器运行时的 Docker Compose | 苹果的 `container` 已经到 1.0，但没人只跑一个容器 —— 大家跑的是含五个服务的 compose 文件；更值得注意的是原生运行时周围开始长出生态，这才是它在 Mac 上成为真正 Docker 替代的条件 |
| **Frond** | 承载应用依赖图的前端运行时 | 它不是路由器也不是渲染器 —— 而是它们下面那一层：每个节点在一处声明如何获取、取消与释放，React 只消费已经就绪的东西；底层跑在 Effect 上，节点被驱逐时请求真的会中断、定时器会清理、流会关闭 |
