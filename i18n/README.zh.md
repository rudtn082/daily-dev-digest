## 这是什么

每天上新的东西太多，跟不完。这就是我的过滤器 —— 每天 3~5 条，各用一行说明为何值得一点。
不限主题：智能体、基础设施、小而巧的工具、模型，偶尔还有奇怪的实验。
每天的清单都冻结在归档里 —— 不会事后悄悄改写。

与所列项目无关。这里的条目是指路，不是推荐 —— 自己去看，自己判断。

## 今天 — 2026-07-28

智能体不再只是造访你的环境，而是开始住进去 —— 你已登录的浏览器会话、团队聊天、文档，以及你自己的硬件里。

| 精选 | 是什么 | 为何引起注意 |
|------|-----------|--------------|
| **ego-lite** | 把你已登录的会话原样交给编码智能体的浏览器 | 多数智能体自动化都从一个空白配置起步，撞上第一道登录墙就结束了；ego-lite 启动时会问要不要迁移 Chrome 数据，于是智能体继承了 Cookie 与扩展，却在自己的 Space 里干活，不碰你的标签页 —— 本周 GitHub 趋势第一，依据是它在四项任务上比 Vercel 的 agent-browser 更快、更省 token 的基准 |
| **Buzz** | 让智能体成为正式成员的 Block 自托管工作区 | 把聊天、git 托管与智能体收进同一界面的 Apache-2.0 项目，底层是 Rust 写的 Nostr 中继；真正的看点不是"Slack 加 GitHub"这句宣传，而是智能体拥有自己的密钥和频道成员身份 —— 提交补丁或批准评审都会以签名事件落进审计日志，而不是一次匿名的机器人操作 |
| **Kimi K3** | 迄今最大的开放权重发布：2.8T 参数 | Moonshot 在 7 月 27 日 00:00 UTC 无门槛放上 Hugging Face —— 96 个分片，MXFP4 约 1.56 TB；但在你基于它开发之前该读的是那份标为 `license:other` 的自定义「Kimi K3 License」，其中带有触发营收后需另签协议的条款和界面署名义务。发布时尚无第三方基准 |
| **OpenWiki** | LangChain 的 CLI，写给智能体而不是人看的文档 | 它生成一个按 LLM 上下文窗口裁剪的 `openwiki/` 目录，并在图胜于文的地方插入 Mermaid 图；与又一个 README 生成器拉开差距的是随附的 GitHub Action —— 每天开一个 PR，把文档腐化从自律问题变成合并队列里的一项 |

## 怎么挑的

- 每天 3~5 条，最多 5 条。没什么亮眼的日子就少放。
- 不重复 —— 每条都对照归档里已有的。
- 比起人尽皆知的大项目，优先正在上升的。
- 没有付费位、没有联盟链接，没有例外。

想推荐一条，或自己复制一份来跑？见 [`CONTRIBUTING.md`](../CONTRIBUTING.md)。
