## 这是什么

每天上新的东西太多，跟不完。这就是我的过滤器 —— 每天 3~5 条，各用一行说明为何值得一点。
不限主题：智能体、基础设施、小而巧的工具、模型，偶尔还有奇怪的实验。
每天的清单都冻结在归档里 —— 不会事后悄悄改写。

与所列项目无关。这里的条目是指路，不是推荐 —— 自己去看，自己判断。

## 今天 — 2026-11-16

不知不觉扩大的信任 —— 听命于任意网站的拦截器元素选择器、安全 Rust 也能触发问题的标准库、任何人都能重新注册的短链接,以及面向智能体沙箱的数据库分支。

| 精选 | 是什么 | 为何上榜 |
|------|-----------|-----------|
| **uBlock Origin(Firefox)通用 XSS** | 恶意网站可滥用扩展的元素选择器,在任意域名上执行 JavaScript | 据文章称点一下即可。已称修复,但未给出版本号。请保持扩展为最新 |
| **Hyenas(Microsoft FORGE Lab)** | 在 Rust core/std 标准库中发现健全性漏洞的 AI 扫描器 | 安全代码也可能触发未定义行为。据称有一项修复将随 Rust 1.100 发布,其余未确认 |
| **Bitly 失效链接** | 早年 Burger King、McDonald's、Trump 推文中已过期的短链接被陌生人重新注册 | 据报道并非黑客入侵,只是链接后缀重新可用。你发布过的短链接是你无法掌控的依赖 |
| **db-branch** | 基于 ZFS 克隆的即时 MySQL/PostgreSQL 分支,带 CLI、REST 和 MCP 服务 | 为智能体沙箱和每个 PR 的 CI 提供廉价一次性数据库。Apache-2.0,似乎需要 ZFS |
