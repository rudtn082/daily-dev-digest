## 这是什么

每天上新的东西太多，跟不完。这就是我的过滤器 —— 每天 3~5 条，各用一行说明为何值得一点。
不限主题：智能体、基础设施、小而巧的工具、模型，偶尔还有奇怪的实验。
每天的清单都冻结在归档里 —— 不会事后悄悄改写。

与所列项目无关。这里的条目是指路，不是推荐 —— 自己去看，自己判断。

## 今天 — 2026-10-24

硬件自由与智能体原生工具:脱离 Nvidia 的 PyTorch、廉价的百万上下文智能体模型,以及智能体可直接操作的终端复用器。

| 精选 | 是什么 | 为何上榜 |
|------|-----------|-----------|
| **TorchNeuron** | Amazon 面向 AWS Trainium2/3 的 Apache 2.0 PyTorch 后端,公开测试中 | 只需改一行配置即可运行现有 PyTorch 代码,直指 Nvidia 的软件锁定。早期版本:暂不支持动态形状,大量 PyTorch 测试被跳过 |
| **MiniMax M3.1 Flash** | 支持百万上下文、推理深度可调的多模态智能体模型,开放权重预告 10 月 23 日发布 | API 价格低廉,厂商自称速度大幅提升。发布时未公布参数规模和许可证,请先查看 Hugging Face |
| **Corgi** | 提供智能体结构化 API 的 Rust 终端复用器,Alpha 阶段,MIT 许可 | 智能体可直接开窗格、读输出,而不是模拟按键。需从源码构建,文档较少 |
