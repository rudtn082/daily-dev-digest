## 今天 — 2026-08-10

这一周，智能体不再借用别人的基础设施，开始拥有自己的 —— 一台机器、可持续的状态、对循环的记忆；而它们脚下的系统层，正被同一批模型重写。

| 精选 | 是什么 | 为何引起注意 |
|------|-----------|--------------|
| **pgrust** | 用 Rust 逐行重新实现的 Postgres，大部分由模型写成 | 与 Postgres 18.3 在协议和方言层面兼容，并通过回归测试套件全部 46,066 项 —— 这是此类项目里唯一真正有分量的数字；更值得读的是作者的复盘：四次尝试、三条死路，花掉约十万美元模型开销才跑通一套可复现的转写流程。性能说法出自作者自测，尚无第三方复现 |
| **celld** | Deno Land 推出的自托管分布式 Durable Objects | 每个对象都是一个独立的 SQLite 数据库，复制到你自己的 S3 存储桶，节点之间仅通过这个桶协调 —— 没有控制平面，也没有需要运维的共识层；分片不再是需要规划的迁移，而成了模型自带的性质。不过版本还是 v0.1.0，眼下适合读架构，不适合承载流量 |
| **@cloudflare/computer** | 给智能体一台机器而非一个容器的 Durable Object 工作区 | 一套文件系统背后挂着多种后端 —— 搬运文件用轻快的 isolate，需要包管理器时经 FUSE 挂上完整 Linux —— 押注的是"一个智能体配一个容器"本就是错误的粒度，与其让你事先选定，不如由运行时按任务分派 |
| **LoopX** | 面向跨会话长期运行的智能体工作的中立状态内核 | 持久目标、可执行 todo、证据日志、感知配额的自动唤醒，以及必须由人签字的显式关卡，摆在 Codex 或 Claude Code 旁边而不取代它们 —— 这是智能体工具里最不光鲜、也最扎人的问题：长任务至今仍死在上下文边界，交接时递过去的是一大段聊天记录 |
| **book-to-skill** | 把技术书变成智能体按需加载的技能 | 章节文件只在你问到该主题时才载入，实测比把整本书塞进上下文回答同一个问题少用 24～51 倍 token —— 比工具本身更值得注意的是这个思路：它悄悄证明了技能可以当作参考资料的索引格式 |
