## 今天 — 2026-09-16

一个 token、一次代码审查、一个 GPU 小时的价格 —— 三个把 AI 成本变成可以自己核对的数字的项目。

| 精选 | 是什么 | 为何引起注意 |
|------|-----------|--------------|
| **Colibri** | 从磁盘流式加载专家，用手头的硬件跑前沿 MoE 模型 | 纯 C、零依赖，把显存、内存和磁盘当作一个分层整体；目前能跑从 OLMoE 到 Kimi K3 的九个模型系列，并与 transformers 做逐 token 一致性校验 —— README 直说“速度由你的磁盘决定”(六张 5090 约 6 tok/s，128GB 内存的 CPU 台式机约 1.8)。问题从“装不装得下”变成了“我的 SSD 值多少 token”。Apache 2.0 |
| **Open Code Review** | 阿里巴巴内部代码审查工具，以 CLI 形式开源 | 文件选择、相关文件打包、规则匹配和评论定位全部写死在流水线里，LLM 智能体只负责判断和检索上下文 —— 项目称 token 消耗约为通用智能体的 1/9，精度还更高(这是他们自己的数据，请在你的仓库上实测)。设计思路是：凡是不需要模型的步骤，都不交给模型。支持 GitHub Actions、GitLab CI，以及 Claude Code、Codex、Cursor 插件。Apache 2.0 |
| **Computable GPU Index** | 公开、可复现的 H100/H200/B200/B300 每小时价格指数 | 对固定供应商样本的加权投票只取中间区间求平均，少数几家拉不动数值；克隆仓库就能重新算出任何一个已发布的值。匿名 API，无需密钥 —— GPU 价格大多由卖 GPU 的人报出，能自己复算的数字对做预算和签合同都有用。代码 Apache 2.0，数据 CC BY-NC |
