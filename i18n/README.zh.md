## 今天 — 2026-09-14

拆开编码智能体 —— 权重、推理服务和运行框架，各自变成可以替换的零件。

| 精选 | 是什么 | 为何引起注意 |
|------|-----------|--------------|
| **OpenSAS** | 由智能体写出的开源 SAS 9.4 解释器 | 用 Zig 实现，由七个编码智能体仅凭公开文档协作完成，声称在完整临床流水线（SDTM、ADaM）上与商业版 SAS 输出逐字节一致——受监管的临床试验产出正是"差不多"就等于失败的领域，比再造一个 todo 应用更能严苛地检验智能体写的软件；一致性是项目方自己的说法，用之前拿你的流水线验证 |
| **GLM-5.3-Flash** | Z.ai 首个原生多模态 GLM-5，MIT 许可 | 320B MoE、激活 18B，1M 上下文，支持文本、图像、视频、文件输入，fp8 权重已上 Hugging Face——在 Z.ai 认领之前，它以"Ox Alpha"之名匿名跑在 OpenRouter 上；没有营收门槛、没有用途限制的许可证，才是你能拿它做产品的关键，比任何榜单图都重要 |
| **Magnitude** | 直接接入你现有智能体的本地推理服务器 | 先探测芯片、内存和带宽，估算每个模型的适配度与 tok/s，再下载、调优并为 Pi、OpenCode、Hermes、Codex、Claude Code、Cline 提供服务——它回答的是本地用户真正卡住的问题：不是"能不能跑模型"，而是"这台机器上哪个模型撑得住智能体循环" |
| **Pi** | 可以拆开用的智能体工具包 | 把多提供商统一 LLM API、智能体运行时、TUI 组件和编码智能体 CLI 拆成独立的包，可嵌入 Node，也可通过 RPC 驱动——它在 GitHub 趋势榜上紧挨着 Magnitude，这个组合本身就是看点：运行框架正在从产品变成库，循环、模型和界面不再由同一家厂商决定 |
